# 配方创建与示教

配方都是**段配方**（分段连拍飞拍）：固定胶枪，机器人抓工件从胶嘴下走过，三台独立相机共用 Line0 高电平门控，按软件设定的固定帧率（默认 10 fps）沿胶路连续采集。本文写段配方的业务行为，规则取舍与实现细节见 [分段连拍决策记录](../decisions/segment-burst.md)。生产现场的相机交付格式、门控时序和毫米精度仍须现场验收。

## 段配方流程

### 业务结构

```text
候选配方（segments 非空）
  ├─ 段列表：沿胶路的直线段 / 弯道段，各段预期帧数 N_exp、帧数容差、段首 / 段尾跳过帧数、检测相机、检测项与允差
  │    └─ 每段的每台检测相机一条走廊与一张示教帧
  ├─ 三台计划相机（共用 Line0 门控，各按设定帧率出帧，按 SDK 帧号配成帧组）
  │    └─ 像素当量、标定引用、检测参数
  ├─ 示教件（一件历史件：分段边界与全部示教帧的来源，兼作基准件与标准件）
  │    ├─ 已确认的分段 → 各段 N_exp（帧组数）、ΣN_exp
  │    └─ 测量示教件 → 单段配方的 x_ref、起涂收尾建议、逐帧定向提示
  ├─ 默认检测参数与按段类型的默认检测项
  ├─ 工件胶路导航图（可选）：候选内编辑，正式发布时独立冻结，不参与检测
  ├─ 独立整圈验证样本与验证记录（可选）
  └─ 待生效的不可变发布版本（发布包格式 schema 5）
```

- 每个帧周期三台相机各出 1 帧，不是一帧里三个视角。帧序号取相机 SDK 帧号，不按到达顺序；同一序号的三帧配成一个帧组，某台缺帧只标“检测不完整”，不改变 OK/NG。三台相机必须互不相同、都是单视角设备。
- 配方里没有“拍照点”，计划是段列表。预期帧数 N_exp 不能手填，取示教件已确认分段里各段的帧组数；新建时各段没有 N_exp（“待示教件分段”），各段都有 N_exp、整件 ΣN_exp 有值之后才能发布。
- 配方结构版本为 8，7 及更早的文件拒绝读取、不迁移，需要重建。发布包结构版本为 5；业务身份用明确的 ID、版本、修订号、帧号与帧组序号，不计算业务内容哈希。

### 页面主线

进度总览把步骤排成 `capture → segments → corridor → calibration → validation → publish`（示教件 → 分段 → 走廊示教 → 试测 → 验证（可选）→ 发布），每步给出完成条件与阻塞原因：有示教件才能分段，示教件边界确认后才能示教走廊，走廊示教完成后才能测量示教件。配方构建的取舍见 [示教件决策](../decisions/recipe-build-flow.md)（RB-1～RB-8）。

### 示教件与历史件

PC 不发起采集，建配方用的图像都来自历史件：先发布采集版，维护模式按它跟着生产采图，攒下的录制件在示教件页的历史件选择器里选用。开发与测试用 `src-tauri/examples/capture_fixture.rs` 按采集版配方用合成图（或样本集原图）生成仿历史录制件（录制目录、`part.json` 与记录库里的维护采集件，所以要先发布采集版，命令见 [测试说明](../testing/TESTING.md)），选择器标“手动配置”，之后与真机件走同一选件、导入路径，供端到端与长稳测试使用。

- **历史件选择器**：列出本配方最近的真机录制件（时间、SN、模式、帧组数、各相机帧数、时长 / 实测帧率（设定）、原图是否完整、不可用原因与提示），选中一行即可按相机、帧组预览原图（只读，读录制目录，不导入）。不可用原因在选择框悬停与原因列都显示；本候选已用作示教件的件标“已使用”，不能重复选。可用条件见 [在线投运](online-commissioning.md) 5.2。
- **导入**：选用即导入，每件物化成一个已完成的采集轮次（原图同卷时链接外部录制原图，跨卷时复制并校验，`round.json` 的 `origin` 记来源），不占用设备、不停线。轮次只是存储格式，界面不显示轮次编号与轮次列表，件都以“时间 · SN”标识。
- **示教件**：每个候选恰好一件，分段边界与全部（段, 检测相机）示教帧只来自它。更换示教件、或从生产配方改版的候选首次设示教件时，清空全部边界、走廊与示教帧、示教件测量及其派生结果（各段 N_exp、x_ref）以及继承的走廊，删除原有的轮次；段列表结构（段数、顺序、类型、检测相机、检测项与容差）与配方级参数保留。没有示教件不能发布。
- **基准与标准件**：示教件即基准件，兼作标准件：各段 N_exp 取它已确认分段的帧组数，单段配方的 x_ref 由测量示教件得出（见“试测”）。不另选标定件或标准件。
- **旧流程候选**：本流程之前建的候选（`workspace.json` 没有 `flow: 2`）在配方库标“旧流程候选，已停用”，不能打开、编辑或发布，由用户删除；删除只删候选与它导入的轮次，同编号的生产配方照常运行，删除后可从它新建候选。发布的正式版在配方文档的可选字段 `teachingPiece` 记示教件来源（时间、SN、`cycleId`），配方库卡片显示“示教件：时间 · SN”。

### 工件胶路导航图

分段工作台可导入完整工件图，沿机器人涂胶方向描折线，标出实际采集起止点及段分界，确认空间对应后保存。闭合胶路也要指定起点；采集范围外显示灰色，不支持跳帧。照片建议接近正上方；透明 PNG 可直接使用。地图可选，没有地图仍可完成原流程。

地图按示教件每段原始帧组序号和折线弧长显示估计位置，缺帧或屏蔽不重排序号。分段草稿仅作预览；多段走廊示教使用已确认边界，单段使用全件范围。点击地图只浏览对应帧；仍须点击“用此帧示教”才能替换示教帧。空间标注与帧边界分别确认，相互不自动修改；图像配准与相机偏移不在首版范围。

地图未保存草稿跨页保留，回到分段页可继续编辑或撤销；保存前不能发布或切换项目；换配方须在配方库确认放弃草稿。换示教件保留图片和空间标注，帧定位等待新件范围有效；修改段结构、图片或路径后需重新确认空间对应。发布页另列导航资料状态，正式发布以同一候选修订冻结独立辅助快照，后续编辑不覆盖旧快照。地图异常只关闭导航，不影响生产加载或判定；规则和验收范围见 [RB-9](../decisions/recipe-build-flow.md#rb-9-工件胶路导航图)。

### 示教件分段与帧组屏蔽

段结构与示教件边界在段列表页的分段标定工作台里按图像定好（见“页面主线”的段列表一行），示教件的边界只在这里确认，确认后各段 N_exp 随之写入。单段配方不需要边界。段类型及顺序来自段列表；有 K 段时设置 K−1 个边界，每个边界表示上一段的最后一个原始帧组，下一段从该序号加一开始。边界必须严格递增，不能产生空段或超出本件范围；三台相机共用同一套边界。比例只提供初始位置，不能证明弯道减速时的边界准确。段结构变化后旧确认失效，N_exp 与 x_ref 清空。

示教件的帧组可按连续区间屏蔽或恢复（试测页的“帧组屏蔽”），屏蔽需填写原因。屏蔽只表示该组图像不参与示教件测量取样，不改已确认的分段，原图和原始序号仍保留，`groupCount`、各相机原始采集计数及缺帧告警均不变。例如 90 组屏蔽第 40–42 组后仍是 90 组，第 43 组不改号；页面另列屏蔽 3 组、未屏蔽 87 组，未屏蔽不等于测量成功。运动暂停、程序错误等异常件应换一件作示教件，不通过屏蔽压缩正常帧数。

已被走廊示教引用的帧组不能直接屏蔽，需先更换示教帧；已屏蔽的帧组不能新选作示教帧。屏蔽或恢复后示教件测量失效、x_ref 清空，需重新测量示教件，不沿用旧结果。

示教件已确认的手动边界给出各段 N_exp；未确认的边界不参与。手动边界本身不接入生产 `Segmenter`：生产与独立样本验证按各段 N_exp 的比例推算每件的边界（D-SB-40，见“判定”），不能通过屏蔽隐藏验证缺陷。不提供永久删除原图或单相机局部屏蔽。

### 走廊示教

走廊只按段示教（决策记录 D-SB-45，取代每台相机一条走廊）：走廊表示胶条在画面上的位置，由工件走到胶路的哪一段决定，所以每一段、它的每台检测相机各一条走廊、一张示教帧。左栏相机行只设相机参数：像素当量（默认取设备菜单“标定”得出的当量，可手填）和可选的检测参数；配方里的当量只在示教帧冻结且相机还没有当量时自动取标定值，之后标定、重新标定都不改配方，“测量”卡片显示这台相机工位标定当前的当量，配方当量为空或与它不同时标“与标定不同”并给出“采用标定当量”；相机下方列出它检测的段，段行才是走廊示教的对象。

选中一段后，在示教件里选这一段内的一帧（示教帧只能取自示教件；多段配方要求示教件已在分段标定里确认分段，只能选本段帧组；单段配方任选），冻结后在这一帧上沿胶路提取（刷选后“自动提取走廊”，或“笔划直接生成走廊”），可编辑点、调整点间距。画布默认“只看”：点图不改走廊，可缩放、平移、拖动扇区把手，选“编辑点”后才加点、拖点，防止看图时误加点。走廊、参数的改动停顿约 0.9 秒后自动保存，保存不锁界面：切段、切相机照常可点（能自动保存的草稿切走后照常保存），提取走廊、选定示教帧、清除本段走廊和试测这类要按已保存配方做的操作，点下去时有待存的改动就先立即保存、存好再执行，保存失败则不执行；只有按站距不足三站、不会自动保存的走廊草稿才拦住切换。保存状态只在顶栏一个固定宽度的标记里显示；拖动扇区把手时只转画面，松手才写进配方；扇区几何由示教页按与测量图相同的规则自己算，保存前后显示不换来源。自动提取沿整条路径检查歧义：两条同样可信的候选即使在末端汇合，也会标记分歧位置并要求调整笔划，避免任意选择一条；笔划明确靠近目标胶路时正常提取。直线段从出胶点一侧起沿胶条画整段；弯道只从出胶点起画一小段，超过 8 mm 提示。走廊至少两点、不短于 1 px 且完整落在示教帧内才算保存；一台相机各段的示教帧必须同尺寸，采集后相机的设备配置不能变。“清除本段走廊”去掉这一段这台相机的走廊与示教帧。在分段标定里改段结构或挪边界后保存，走廊按示教件上的帧范围逐段对应（D-SB-52）：没动的段原样保留，示教帧被挪出原段、所在段改了类型或拆分后不含示教帧的那一半要重新示教，保存前的确认弹窗逐条列出；从某段去掉一台检测相机时，它在这一段的走廊与示教帧一并去掉。

测量示教件按已确认的边界，每帧只由所在段的检测相机用该段走廊测量。生产时帧到达即按累计 N_exp 预测所属段送测，收尾后按比例边界解析区域，对归属变了或过渡区需要另一侧走廊的帧补测后再判定；不检测某段的相机，这一段的帧记“本段不检测”，不判定也不计检测不完整。

这一段已有示教帧时重新选帧，先预览示教件里的候选帧；确认“用此帧示教”后才更换已保存的示教帧并返回走廊编辑。

弯道帧里胶条走出走廊时，这一帧记“检测不完整”，不判 NG。这个走廊模型还没有用真实弯道图验证（决策记录 D-SB-17）。

### 试测

试测页（`/recipe/calibration`）围绕示教件：示教件即基准件，兼作标准件（[RB-3](../decisions/recipe-build-flow.md)），不另选标定件。

- 示教件基准：逐段列出 N_exp（示教件已确认分段里这一段的帧组数，分段确认时自动写入）、帧数容差、x_ref 或待定原因与逐帧定向提示；ΣN_exp 取各段之和，Σtol 为各段容差之和。容差默认取段类型默认值 2 帧（直线、弯道），可逐段键入后点“确认容差”修改，不给建议值。帧组数越界只告警；本件总帧组数超出 ΣN_exp ± Σtol 时按未分段处理（见“判定”）。
- 测量示教件：示教件分段已确认、走廊示教完成后点“测量示教件”，用已示教的走廊按示教件分段测量每一帧（每帧只由所在段的检测相机用该段走廊测），替换原有的测量；有未保存的改动时先保存再测。走廊、当量、检测参数、站距、出胶点、定向参数、专家参数或扇区方向改了，测量失效、x_ref 自动清空，需重新测量。
- x_ref 只用于单段配方的直线段：参考相机去掉首尾各一帧（再去掉示教件的起涂、收尾帧）后，取测成帧的胶中心 x 均值（AbsoluteX），或 `ToEdge`（到边缘距离，D-SB-48）没填图纸胶边距时取胶边距均值；不能手填，只有一件，离散记 0。多段配方暂不计算 x_ref，不阻断发布。`ToEdge` 填了图纸胶边距时以它为参考，不需要示教件得出的值，多段配方也能判。
- 起涂与收尾跳过（D-SB-50）：整件开头出胶有延迟、胶条要走满测量区间，末尾同理，这些帧组按本段检测项会判断胶。按示教件测量时的每帧特征给出第 1 段段首、末段段尾的跳过帧数建议：本段检测相机都测成且没有 NG 级发现的帧组算成形，连续 2 个成形之前的帧组数即起涂（收尾）帧数；成形之前有缺帧、测量失败、走出走廊或已屏蔽的帧组时不给建议并写明原因。有测量即给建议，没测量时提示先测量示教件。点“采用建议”才写入段首 / 段尾跳过帧数（不换计划版本）；当前值小于建议时提示正常件会判断胶。
- 逐帧定向提示（D-SB-47）：取自示教件测量，开启定向的段核对检测窗口能否覆盖每帧后移量（段长 ÷ N_exp）、没找到胶条的帧是否超过 20%，只提示、不阻断发布。
- 逐帧查看：按帧组 × 计划相机列出测量示教件时的每帧状态，帧组上方标出按已确认边界所属的段。点一帧读原图，并按当前段走廊重测（只读，不改测量），叠出走廊、搜索带与测到的两侧胶边，旁边列胶宽最小 / 均值 / 最大、胶中心偏移 x、最长断胶与有胶站比例；重测状态与测量时不同说明走廊或参数后来改过，重新测量示教件即可更新。方向键切换帧组、相机。
- 历史件试测：直接列出本配方的历史件，每件“触发测试”用当前候选从录制原图重测并判定（`workspace_compare`，raw），结果另存为对照、不改历史记录；有改动等着自动保存时先立即保存再测。“看详情”打开历史记录详情并选中这次对照（详情页的返回按钮回到试测页）：帧组条、段布置、整件与区域结论和每帧指标按对照结果显示，选中的帧组三台相机原图并排，各自叠出复测所用的走廊、搜索带与测到的胶边，可切回原始记录。原图下方是选中相机这一帧的逐站胶宽折线（横轴沿胶路距离 = 站号 × 站距；无胶的站断开并标灰色“断胶”带；叠胶宽上下限与溢胶上限参考线，超限点标红）：悬停折线上的站，原图上这一站的测量线加粗换色；悬停原图上的测量线，折线标出同一站。原记录没有区域判定（如维护采集件）时不做逐区域对比，没有发布包时不能按原发布包重现，两者都只给灰色说明。
- 换示教件或改分段使 ΣN_exp 变化时，发布会分配新的计划版本；PLC 只发型号，不需要同步帧数。

### 判定

三台相机取最差：任一相机任一帧 NG，所在区域即 NG，整件取最严重结论。每帧独立检测胶宽、断胶和溢胶（某帧最大胶宽超过溢胶上限判 NG，PLC 结果码沿用 NG_WIDTH，原因写“溢胶”）；气泡、拉丝不检，结果标“未检项”。分段按 D-SB-40：多段配方各段都有 N_exp 时，本件收尾后按各段 N_exp 的比例与本件帧组数推算边界；帧组数在 ΣN_exp ± Σtol 内时边界可信，每个边界两侧各 `boundaryGuard` 帧（段列表页“边界过渡帧数”，默认 2、可配 0–5）为过渡区，只按两侧较宽的允差判每帧胶宽、断胶、溢胶，不判胶偏；其余帧按所属直线 / 弯道段判，直线段核心区域去首尾各一帧判胶偏（多段配方没有 x_ref 时标“胶偏未判”）。单段配方、有段还没有 N_exp 或帧组数越界时整条胶路按一个未分段区域判：只跑每帧独立检测，不判胶偏。帧组数不在 ΣN_exp ± Σtol 内只记“帧数异常”告警，不逐段核对帧数；缺帧只标“检测不完整”；都不改变 OK/NG，整件没有一帧测成才判 ERR（91）。PLC 提前报工件结束时用已收到的帧照常判，帧组数小于 ΣN_exp − Σtol 时加 `short_part` 标记。各段段首 / 段尾跳过的帧不判定、不计检测不完整，结果按帧组号列为“未检区域”；分段生效前只有整件起头（第 1 段段首）与收尾（末段段尾）能定位（D-SB-22 修订）。原按毫米的检测区间已停用。

### 发布

发布前检查：相机配置（相机组里有这三台计划相机、来源一致、单视角独立；不要求在线，接件时再查）；示教件（候选已设示教件，RB-8）；走廊示教（恰好三台计划相机；每段每台检测相机都有示教帧、走廊完整落在帧内；每台相机有像素当量；各示教帧采集后相机的设备标签没变）；段帧数（各段 N_exp 都已由示教件分段得出，逐段列出 N_exp ± 容差或“待示教件分段”；多段配方里 N_exp 短于 2 × 过渡帧数 + 1 的直线段提示两侧过渡区取空后不判胶偏，逐帧定向提示同样只提示、不阻断）；示教件采集参数（测量示教件时的相机采集参数与当前相机配置一致）；胶偏参考 x_ref（只在有启用胶偏检查的直线段时列出参考值或不判的原因，不阻断：单段配方运行时整条胶路按未分段处理、不判胶偏；多段配方暂不计算 x_ref，该段标胶偏未判；`ToEdge` 填了图纸胶边距即按它判）；生产版本。这些检查在打开发布页和点发布时当场核对，全部满足即可发布（决策记录 D-SB-46：不再要求独立样本验证）。

独立样本验证可选：样本取自原图齐全、段结构相同的生产历史（本候选的示教件不行；录制有相机设备记录时，设备配置须与当前一致），按生产同一规则选走廊重测；缺帧只算检测不完整，帧组数超出 ΣN_exp ± Σtol 只写进样本原因，不改变是否符合；结果只供参考，不影响发布。验证运行期间或之后设备、标定、引擎、候选修订或生产基础版本变化，需要重新验证。

发布成 schema 5 发布包：先生成不可变包并保存待生效版本，冻结该候选；当前工件继续持有原配方快照，在完整工件与 PLC 事务边界切换。失败保留原因和同一个待生效包，人工重试切换，不重复生成版本；也可放弃待生效版本。

### 采集版（在线投运）

新产线正常生产、还没有可用配方时，先把未完成的候选发布成**采集版**（配方 `stage = collect`），维护模式按它的型号与三台计划相机跟着生产采图；攒够历史件后选示教件、分段、示教、试测，按需验证，发布**正式版**（`stage = formal`，即上一节的完整发布）。维护模式下找不到配方的件不录图，所以新型号要先发布采集版再攒件。在线投运的整体方案见 [在线投运](online-commissioning.md)。

- 发布前检查只有：恰好三台互不相同的计划相机；都在当前相机组里且是单视角独立相机；型号不与其他生产配方冲突；至少一段（可以是一个直线段占位）；生产版本（候选基于当前生产版本，且还没有正式版）。不要求走廊示教、ΣN_exp 与独立验证，不生成发布包。
- 版本号照常递增，计划版本照常由配方库分配（PLC 只发型号），同样在工件边界生效；验证与发布页的确认框逐条列出未满足的项，全部满足才能确认。
- 采集版之后照常继续示教、试测、验证，发布正式版即替换；正式版不能降级：已有正式版时拒绝发布采集版（检查项与配方库写入两处都拒绝）。
- 正常模式接件遇到采集版一律不检测（“配方只有采集版，仅维护模式可用”），本件照常运动，工件结束后回 90/95；只有维护模式按采集版采图，不判定。

### 维护模式（在线投运）

在线检测页开启维护模式（须填原因），从下一件起 PC 置 pcMode=1、每件照常接件采图，回 PLC 结果码 0（按未检放行），不输出 NG：

- 采集版配方：只录图不判定，不论录制设置都录全部帧；录制目录带保留标记，不被自动清理。
- 正式版配方：照常测量判定（试判），结论入历史但不进当日合格率，也不输出给 PLC。
- 找不到配方或配方、设备有问题：不回检测错误，结果码 0 放行，原因记进本件记录（不录图）。

在线检测页按配方显示“已录 N 件，其中完整可用 M 件”（完整可用：录制完整、各计划相机帧数一致且非零），示教件只需一件，历史件试测与验证另需若干。退出维护模式前列出仍只有采集版的配方：退出后这些型号回 90/95。实现取舍见 [维护模式决策](../decisions/maintenance-mode.md)。

## 候选配方离线试运行

在线检测页的“候选配方离线试运行”只在离线样本集模式提供，选择已保存候选和样本件后单圈运行；验证与发布页提供入口。每次运行冻结候选修订、测量图、图像尺寸与引擎，继续走采集、测量、判定和离线 S7 握手，不发布候选、不写入生产配方。样本帧按 [离线样本集格式](../integration/sample-set-format.md) 的段配方解释取：每台计划相机按清单顺序的第 seq 帧。

运行中及结果显示候选编号和修订，并标注调试。历史记录单列“候选调试”，不计入真机或普通离线统计；调试通过不代表试测、独立样本验收或生产发布通过。候选须满足发布就绪（三台计划相机都有走廊与像素当量、ΣN_exp 有值），各计划相机的示教帧采集后设备配置没变，按示教帧尺寸建走廊测量图；同时保留结构、尺寸、计数和会话校验。

飞拍可行性计算器允许手填像素当量；修改其他来源参数时保留手填值，仅在明确恢复来源值时替换。此值用于当前页估算，不写入示教标定或替代标定验证。

离线样本模式的主设备状态不使用生产发布条件判定候选调试；已发布配方回放有独立入口与检查范围。候选启动仍由后端核对示教、样本、设备及周期状态。历史按记录自身来源展示，不能随当前站点模式改变身份。进入或退出离线后清除上一次当前工件、结果与实时图像显示，统计恢复当前站点范围；历史数据库与候选示教保持不变。

## 验收分层

段配方的全流程（合成图三相机从建站到投产）由软件回归覆盖，测试入口见 [测试记录](../testing/TESTING.md)。软件流程测试不代表实体相机、PLC 接线或算法质量已经验证；真实样本集 gs-20261017 是停稳拍数据，只作冒烟。

3 × 25 Hz 吞吐门槛口径不改，尚未达标也没有被直接验证：须在现场工控机上用真实相机来源跑 `pnpm test:soak:throughput`，再决定降低相机帧率还是加测量并发。

现场仍需确认：拿到按量产曝光与速度拍的含弯道三相机图像，验证分段算法与“每台相机一条直线走廊”的模型（D-SB-17）；核对三台相机共用门控的接线、SDK 帧号来源与三路带宽（约 826 Mbps 的估算超过单个千兆口 80% 预算）；用真实良品、断胶、偏位、宽度异常样本验证检测质量，并检查实际采集速度下的带宽、写盘和连续运行表现。
