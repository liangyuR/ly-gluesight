# 配方创建与示教

配方都是**段配方**（分段连拍飞拍）：固定胶枪，机器人抓工件从胶嘴下走过，三台独立相机共用 Line0 高电平门控，按软件设定的固定帧率（默认 10 fps）沿胶路连续采集。本文写段配方的业务行为，规则取舍与实现细节见 [分段连拍决策记录](../decisions/segment-burst.md)。生产现场的相机交付格式、门控时序和毫米精度仍须现场验收。

## 段配方流程

### 业务结构

```text
候选配方（segments 非空）
  ├─ 段列表：沿胶路的直线段 / 弯道段，各段预期帧数 N_exp、帧数容差、段首 / 段尾跳过帧数、检测相机、检测项与允差
  │    └─ 每段的每台检测相机一条走廊与一张示教帧
  ├─ 三台计划相机（共用 Line0 门控，各按设定帧率出帧，按 SDK 帧号配成帧组）
  │    └─ 像素当量、标定引用、检测参数
  ├─ 采集轮次（多轮，含标准件轮次）→ 多轮标定 → ΣN_exp、各段 N_exp 与建议容差、标准件 x_ref
  ├─ 默认检测参数与按段类型的默认检测项
  ├─ 独立整圈验证样本与验证记录（可选）
  └─ 待生效的不可变发布版本（发布包格式 schema 5）
```

- 每个帧周期三台相机各出 1 帧，不是一帧里三个视角。帧序号取相机 SDK 帧号，不按到达顺序；同一序号的三帧配成一个帧组，某台缺帧只标“检测不完整”，不改变 OK/NG。三台相机必须互不相同、都是单视角设备。
- 配方里没有“拍照点”，计划是段列表。预期帧数 N_exp 不能手填，只能由多轮采集得出；新建时各段“待标定”，整件预期总数 ΣN_exp 有值之后才能发布。
- 配方结构版本为 8，7 及更早的文件拒绝读取、不迁移，需要重建。发布包结构版本为 5；业务身份用明确的 ID、版本、修订号、帧号与帧组序号，不计算业务内容哈希。

### 页面主线

进度总览把步骤排成 `capture → segments → corridor → calibration → validation → publish`，每步给出完成条件与阻塞原因。

| 采集轮次（`/recipe/capture`） | 导入轮次：在“从历史选用”页签把维护模式录制的完整件导入为轮次（见下文“历史件导入”），或导入带轮次的手动配置数据。每轮是一件工件的一次完整行程，导入时可标为标准件。本页另有轮次结果、轮次整理、加入标定与走廊示教入口。曝光与增益按相机在相机页保存，不属于配方 |

| 走廊示教（`/recipe/teach`） | 右栏按作用范围分卡片，每张卡片标题行带状态徽标与展开箭头，折叠时显示一行摘要。选相机时：“测量”设像素当量、检测参数（来源选配方默认或本相机自定义，只有一组字段）与配方站距；“逐帧定向”设这台相机各段共用的检测窗口（距出胶点的起点与长度，D-SB-47）并查看、清除出胶点，有段开了定向却缺窗口时自动展开。选段时：段标题（示教状态、画法提示、清除本段走廊）；“逐帧定向”设本段开关与方向容差（D-SB-47，默认关闭），开启后在同一卡片里调检测窗口、看出胶点，对照示教帧上的叠加（黄色实线扇形为方向范围）；“检测项”设胶宽、断胶、溢胶，直线段另有胶偏与胶偏参考（选“到边缘距离”时设找边参数与可选的图纸胶边距，D-SB-48），可套用到其余同类段；末行显示这台相机的测量参数并可跳回相机视图。段参数有空值或越界时只提示、不写配方。每条段走廊按配方站距至少 3 站（lyFlow 1.1 的 `glue.bead_width` 少于 3 站时不报错，但把有胶的帧都测成无胶）：保存走廊（含自动保存）和改站距时都先按站数校验，不足时写明实际站数、可用的最大站距或需要的走廊长度，不写配方；后端建测量图时同样拒绝并给出同样的说明。出胶点在开启定向的段的示教帧上用“标出胶点”标定（未标定时按走廊起点推算），示教帧上叠加出胶点、检测窗口环带、方向范围与搜索扇区供核对；每一段、它的每台检测相机从一轮完整采集里选这一段内的一帧冻结，在这一帧上提取并保存这一段的走廊；示教帧下方“本段试测”用候选已保存的走廊与定向参数只读地测示教轮次里本段的帧：“全段试测”给出逐帧状态条（测到、定向回退、无胶、出走廊、测量失败、缺帧），点任一帧在画布上看原图、测到的胶边与实测方向，← → 切帧，“回到示教帧”继续编辑；走廊有未保存的修改、参数正在保存或工件正在检测时不能试测，候选改动后全段结果标为过期（`workspace_teach_preview_segment`、`workspace_teach_preview_frame`）；全部（段, 相机）都保存、相机都有当量后完成（D-SB-45） |
| 多轮标定（`/recipe/calibration`） | 把完整采集轮次加入标定（至少 `calibrationRounds` 轮，默认 10，可配 10–100；标准件轮次不计入），点“应用标定”得出 ΣN_exp，再逐段确认容差 |
| 发布（`/recipe/validation`） | 发布前检查（当场核对）满足即可发布，在工件边界生效；独立样本验证可选（D-SB-46）。另有“发布采集版”（见下文） |

### 采集轮次与轮次来源

轮次只有两个来源，PC 不发起采集：

1. **维护模式采集后导入**：先发布采集版，维护模式按它跟着生产采图，再在采集轮次页“从历史选用”导入（见下文“历史件导入”）。
2. **手动配置数据**：通过“导入配方”导入带轮次的[配方迁移包](storage-layout.md#配方迁移包)。这类轮次的 `origin` 为 `{kind: "prepared", label}`，规则与历史件导入相同：状态只能是完成，不带 PLC 字段。目前由 `src-tauri/examples/capture_fixture.rs` 按候选配方用合成图生成，供端到端与长稳测试使用，界面不另设入口。

- 采集轮次页显示每轮帧组数、各相机帧数、不完整帧组与丢帧告警（只告警）。
- 磁盘上已有的示教实拍轮次（`round.json` 格式 2 带 `teachingRoundId`，或格式 3）照常读取，可继续用于走廊示教和标定；`waitingStart / receiving / draining` 等状态只出现在这类轮次里。

#### 历史件导入

采集轮次页的“从历史选用”页签列出本配方最近的真机录制件和不能导入的原因，勾选后批量导入，每件成为一个已完成的采集轮次（原图同卷时链接外部录制原图，跨卷时复制并校验，`round.json` 的 `origin` 记来源），不占用设备、不停线。可用条件、标准件标记与物化方式见 [在线投运](online-commissioning.md) 5.2。导入的轮次在采集结果里标“历史件导入”，之后走廊示教、分段复核、帧组屏蔽与多轮标定都与其他来源的轮次相同；导入时标为标准件的轮次加入标定时按标准件轮次。

### 轮次分段复核与帧组屏蔽

段结构与模板轮边界优先在段列表页的分段标定工作台里按图像一次定好（见“页面主线”的段列表一行）；其余轮次在工作台下方“其余轮次复核”里确认：软件按图像把模板边界对齐到所选轮次，逐个边界并排对照模板与本轮两侧的帧，← → 微调、Enter 确认，全部确认后一次保存（D-SB-44）。采集页的轮次整理仍可按数字边界、按比例或原帧号套用模板并确认，屏蔽与恢复只在采集页。段类型及顺序来自段列表；有 K 段时设置 K−1 个边界，每个边界表示上一段的最后一个原始帧组，下一段从该序号加一开始。边界必须严格递增，不能产生空段或超出本轮范围。保存草稿后，通过边界附近的原图复核并确认；三台相机共用同一套边界。

已确认轮次可以设为当前配方的分段模板。其他轮次可显式按原帧号或总帧组数比例套用，结果始终是待确认草稿；套用保留目标轮次自己的屏蔽记录，不复制模板的异常帧组。比例只提供初始位置，不能证明弯道减速时的边界准确。段结构变化后旧确认失效；模板还校验采集配置（不含曝光增益），不能跨不匹配的采集条件直接套用。

帧组可按连续区间屏蔽或恢复，屏蔽需填写原因。屏蔽仅表示该组图像不参与标定测量取样，原图和原始序号仍保留，`groupCount`、各相机原始采集计数及缺帧告警均不变。例如 90 组屏蔽第 40–42 组后仍是 90 组，第 43 组不改号；页面另列屏蔽 3 组、未屏蔽 87 组，未屏蔽不等于测量成功。运动暂停、程序错误等异常轮次应整轮移出标定，不通过屏蔽压缩正常帧数。

已被走廊示教引用的帧组不能直接屏蔽，需先更换示教帧；已屏蔽的帧组不能新选作示教帧。已加入标定轮次的边界或屏蔽发生变化时，该轮移出标定并清除派生标定结果；整理完成后重新加入、应用标定并验证。手动移出标定同样清除派生结果，其余轮次保留，重新应用标定时仍需满足轮数要求。屏蔽恢复同样需要重新计算，不沿用旧结果。

已确认的手动边界用于多轮标定的逐段标定（见“多轮标定”）；草稿或模板套用后未确认的边界不参与。手动边界本身不接入生产 `Segmenter`：生产与独立样本验证按逐段标定得出的各段 N_exp 比例推算每件的边界（D-SB-40，见“判定”），不能通过屏蔽隐藏验证缺陷。不提供永久删除原图或单相机局部屏蔽。

### 走廊示教

走廊只按段示教（决策记录 D-SB-45，取代每台相机一条走廊）：走廊表示胶条在画面上的位置，由工件走到胶路的哪一段决定，所以每一段、它的每台检测相机各一条走廊、一张示教帧。左栏相机行只设相机参数：像素当量（默认取设备菜单“标定”得出的当量，可手填）和可选的检测参数；相机下方列出它检测的段，段行才是走廊示教的对象。

选中一段后，在一轮完整采集里选这一段内的一帧（多段配方要求这一轮已在分段标定里确认手动分段，只能选本段帧组；单段配方任选），冻结后在这一帧上沿胶路提取（刷选后“自动提取走廊”，或“笔划直接生成走廊”），可编辑点、调整点间距。直线段从出胶点一侧起沿胶条画整段；弯道只从出胶点起画一小段，超过 8 mm 提示。走廊至少两点、不短于 1 px 且完整落在示教帧内才算保存；一台相机各段的示教帧必须同尺寸，采集后相机的设备配置不能变。“清除本段走廊”去掉这一段这台相机的走廊与示教帧。段的类型序列变化时全部走廊清空；从某段去掉一台检测相机时，它在这一段的走廊与示教帧一并去掉。

多轮标定按已确认的边界，每帧只由所在段的检测相机用该段走廊测量。生产时帧到达即按累计 N_exp 预测所属段送测，收尾后按比例边界解析区域，对归属变了或过渡区需要另一侧走廊的帧补测后再判定；不检测某段的相机，这一段的帧记“本段不检测”，不判定也不计检测不完整。

未完成及失败的轮次不作为示教来源。从采集结果点击“用于走廊示教”会直接打开本轮选帧，即使这一段已有示教帧，也先预览本轮候选帧；确认“用此帧示教”后才更换已保存的示教帧并返回走廊编辑。

弯道帧里胶条走出走廊时，这一帧记“检测不完整”，不判 NG。这个走廊模型还没有用真实弯道图验证（决策记录 D-SB-17）。

### 多轮标定

同一工件程序连续采集多轮，在“多轮标定”页把完整轮次加入标定；标记为标准件的轮次（含导入时标为标准件的历史件轮次）另用于胶偏参考 x_ref，不计入轮数。点“应用标定”：每轮取整件帧组数，均值四舍五入作 ΣN_exp，记录各轮 min / max / mean，并给出建议容差 = max(默认容差, N − min, max − N)；容差由操作员逐段确认后才写入。

- 单段配方同时写该段 N_exp 与统计。多段配方只有在每个标定轮次（不含标准件）都在采集页确认了手动分段时才逐段标定：按边界得出每轮各段帧组数，各段分别取均值四舍五入作 N_exp、记录 min / max / mean 并给出建议容差，ΣN_exp 取各段之和（取整可能与整件均值差一两帧，ΣN_exp 只用于帧数告警）；有轮次未确认分段时各段保持“待标定”并列出这些轮次，ΣN_exp 取整件均值，凭它即可发布。多段配方的 x_ref 仍不计算。各段都标定后运行时按比例分段（见“判定”），否则整条胶路按一个未分段区域判；帧数都只核对整件帧组数 ∈ ΣN_exp ± Σtol。
- x_ref 只用于直线段，由标准件轮次去掉首尾各一帧后取均值得出，不能手填；只有单段配方会算。`ToEdge`（到边缘距离，D-SB-48）取胶边距均值；填了图纸胶边距时以它为参考，不需要标准件，多段配方也能判。
- 重新标定使 ΣN_exp 变化时，发布会分配新的计划版本；PLC 只发型号，不需要同步帧数。
- 逐帧查看（标定页底部）：选一轮已加入标定的采集，按帧组 × 计划相机列出加入标定时测得的每帧状态，帧组上方标出按已确认边界所属的段。点一帧读原图，并按当前段走廊重测（只读，不改标定），叠出走廊、搜索带与测到的两侧胶边，旁边列胶宽最小 / 均值 / 最大、胶中心偏移 x、最长断胶与有胶站比例；重测状态与加入标定时不同说明走廊或参数后来改过，要更新特征需移出这一轮后重新加入。方向键切换帧组、相机。

### 判定

三台相机取最差：任一相机任一帧 NG，所在区域即 NG，整件取最严重结论。每帧独立检测胶宽、断胶和溢胶（某帧最大胶宽超过溢胶上限判 NG，PLC 结果码沿用 NG_WIDTH，原因写“溢胶”）；气泡、拉丝不检，结果标“未检项”。分段按 D-SB-40：多段配方各段都已逐段标定时，本件收尾后按各段 N_exp 的比例与本件帧组数推算边界；帧组数在 ΣN_exp ± Σtol 内时边界可信，每个边界两侧各 `boundaryGuard` 帧（段列表页“边界过渡帧数”，默认 2、可配 0–5）为过渡区，只按两侧较宽的允差判每帧胶宽、断胶、溢胶，不判胶偏；其余帧按所属直线 / 弯道段判，直线段核心区域去首尾各一帧判胶偏（多段配方没有 x_ref 时标“胶偏未判”）。单段配方、有段待标定或帧组数越界时整条胶路按一个未分段区域判：只跑每帧独立检测，不判胶偏。帧组数不在 ΣN_exp ± Σtol 内只记“帧数异常”告警，不逐段核对帧数；缺帧只标“检测不完整”；都不改变 OK/NG，整件没有一帧测成才判 ERR（91）。PLC 提前报工件结束时用已收到的帧照常判，帧组数小于 ΣN_exp − Σtol 时加 `short_part` 标记。各段段首 / 段尾跳过的帧不判定、不计检测不完整，结果按帧组号列为“未检区域”；分段生效前只有整件起头（第 1 段段首）与收尾（末段段尾）能定位（D-SB-22 修订）。原按毫米的检测区间已停用。

### 发布

发布前检查：相机配置（相机组里有这三台计划相机、来源一致、单视角独立；不要求在线，接件时再查）；走廊示教（恰好三台计划相机；每段每台检测相机都有示教帧、走廊完整落在帧内；每台相机有像素当量；各示教帧采集后相机的设备标签没变）；段标定（单段配方有 ΣN_exp 即通过，多段配方要各段 N_exp 都已标定，逐段列出 N_exp、“待逐段标定”或“待标定”；多段配方里 N_exp 短于 2 × 过渡帧数 + 1 的直线段提示两侧过渡区取空后不判胶偏，不阻断）；标准件 x_ref（只在有启用胶偏检查的直线段时列出；`ToEdge` 填了图纸胶边距即通过；多段配方暂不计算 x_ref、没配找边参数的 `ToEdge` 列出原因、不阻断）；生产版本。这些检查在打开发布页和点发布时当场核对，全部满足即可发布（决策记录 D-SB-46：不再要求独立样本验证）。

独立样本验证可选：样本取自原图齐全、段结构相同的生产历史（已导入为本候选轮次并用于示教或标定的历史件不行；录制有相机设备记录时，设备配置须与当前一致），按生产同一规则选走廊重测；缺帧只算检测不完整，帧组数超出 ΣN_exp ± Σtol 只写进样本原因，不改变是否符合；结果只供参考，不影响发布。验证运行期间或之后设备、标定、引擎、候选修订或生产基础版本变化，需要重新验证。

发布成 schema 5 发布包：先生成不可变包并保存待生效版本，冻结该候选；当前工件继续持有原配方快照，在完整工件与 PLC 事务边界切换。失败保留原因和同一个待生效包，人工重试切换，不重复生成版本；也可放弃待生效版本。

### 采集版（在线投运）

新产线正常生产、还没有可用配方时，先把未完成的候选发布成**采集版**（配方 `stage = collect`），维护模式按它的型号与三台计划相机跟着生产采图；攒够历史件后在采集轮次页“从历史选用”导入为采集轮次，再示教、标定、验证，发布**正式版**（`stage = formal`，即上一节的完整发布）。维护模式下找不到配方的件不录图，所以新型号要先发布采集版再攒件。在线投运的整体方案见 [在线投运](online-commissioning.md)。

- 发布前检查只有：恰好三台互不相同的计划相机；都在当前相机组里且是单视角独立相机；型号不与其他生产配方冲突；至少一段（可以是一个直线段占位）；生产版本（候选基于当前生产版本，且还没有正式版）。不要求走廊示教、ΣN_exp 标定与独立验证，不生成发布包。
- 版本号照常递增，计划版本照常由配方库分配（PLC 只发型号），同样在工件边界生效；验证与发布页的确认框逐条列出未满足的项，全部满足才能确认。
- 采集版之后照常继续示教、标定、验证，发布正式版即替换；正式版不能降级：已有正式版时拒绝发布采集版（检查项与配方库写入两处都拒绝）。
- 正常模式接件遇到采集版一律不检测（“配方只有采集版，仅维护模式可用”），本件照常运动，工件结束后回 90/95；只有维护模式按采集版采图，不判定。

### 维护模式（在线投运）

在线检测页开启维护模式（须填原因），从下一件起 PC 置 pcMode=1、每件照常接件采图，回 PLC 结果码 0（按未检放行），不输出 NG：

- 采集版配方：只录图不判定，不论录制设置都录全部帧；录制目录带保留标记，不被自动清理。
- 正式版配方：照常测量判定（试判），结论入历史但不进当日合格率，也不输出给 PLC。
- 找不到配方或配方、设备有问题：不回检测错误，结果码 0 放行，原因记进本件记录（不录图）。

在线检测页按配方显示“已录 N 件，其中完整可用 M 件”（完整可用：录制完整、各计划相机帧数一致且非零），标定至少需要 10 件，验证另需若干。退出维护模式前列出仍只有采集版的配方：退出后这些型号回 90/95。实现取舍见 [维护模式决策](../decisions/maintenance-mode.md)。

## 候选配方离线试运行

在线检测页的“候选配方离线试运行”只在离线样本集模式提供，选择已保存候选和样本件后单圈运行；验证与发布页提供入口。每次运行冻结候选修订、测量图、图像尺寸与引擎，继续走采集、测量、判定和离线 S7 握手，不发布候选、不写入生产配方。样本帧按 [离线样本集格式](../integration/sample-set-format.md) 的段配方解释取：每台计划相机按清单顺序的第 seq 帧。

运行中及结果显示候选编号和修订，并标注调试。历史记录单列“候选调试”，不计入真机或普通离线统计；调试通过不代表标定、独立样本验收或生产发布通过。候选须满足发布就绪（三台计划相机都有走廊与像素当量、ΣN_exp 有值），各计划相机的示教帧采集后设备配置没变，按示教帧尺寸建走廊测量图；同时保留结构、尺寸、计数和会话校验。

飞拍可行性计算器允许手填像素当量；修改其他来源参数时保留手填值，仅在明确恢复来源值时替换。此值用于当前页估算，不写入示教标定或替代标定验证。

离线样本模式的主设备状态不使用生产发布条件判定候选调试；已发布配方回放有独立入口与检查范围。候选启动仍由后端核对示教、样本、设备及周期状态。历史按记录自身来源展示，不能随当前站点模式改变身份。进入或退出离线后清除上一次当前工件、结果与实时图像显示，统计恢复当前站点范围；历史数据库与候选示教保持不变。

## 验收分层

段配方的全流程（合成图三相机从建站到投产）由软件回归覆盖，测试入口见 [测试记录](../testing/TESTING.md)。软件流程测试不代表实体相机、PLC 接线或算法质量已经验证；真实样本集 gs-20261017 是停稳拍数据，只作冒烟。

3 × 25 Hz 吞吐门槛口径不改，尚未达标也没有被直接验证：须在现场工控机上用真实相机来源跑 `pnpm test:soak:throughput`，再决定降低相机帧率还是加测量并发。

现场仍需确认：拿到按量产曝光与速度拍的含弯道三相机图像，验证分段算法与“每台相机一条直线走廊”的模型（D-SB-17）；核对三台相机共用门控的接线、SDK 帧号来源与三路带宽（约 826 Mbps 的估算超过单个千兆口 80% 预算）；用真实良品、断胶、偏位、宽度异常样本验证检测质量，并检查实际采集速度下的带宽、写盘和连续运行表现。
