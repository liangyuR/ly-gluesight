# 工件边缘中心距检测方案

状态：方案草案，待阶段 A 现场验证后进入实施。记录日期：2026-10-20。

源码基线：GlueSight `c74a9f7926e365cea9b2ef6b735b70e5e7585e1b`；LyFlow `5cefe3c75b227d138f1435ae7d6e7486b397926b`。外部资料见 [方法与资料调研](../research/glue-position-methods.md)。

## 摘要

- **要解决的问题**：现场要判断胶条是否打在工件规定位置，例如胶条中心距指定工件边 3～5 mm。现有位置测量以固定示教中线为基准，工件和胶一起移动时会混入结果。
- **做法**：新增“工件边缘中心距”位置模式。每帧在示教测点上沿法向同时找工件边和胶条两边，用胶中心到工件边的有向距离按 N～M 判定。“示教中线偏移”模式保留，按拍照点选择。
- **第一版范围**：每个 Pose 一张检测图、局部直线工件边、胶在工件边的指定一侧；复用现有测点、站距、法向和判定参数。
- **实施前提**：阶段 A 用现场图确认工件边在检测图中可见、能稳定检出，且高度差和视差在可接受范围内（见第 2 节）。
- **待定事项**：具体工艺边、N～M 的严格程度、基准短段丢失容忍长度、配方 schema，均在阶段 A 后定稿。

## 1. 测量定义

在测量平面内，第 i 个测点上：

```text
E_i：工件边点
n_i：单位法向，从工件边指向涂胶侧
B_i：胶条两侧边缘的中点
d_i = (B_i - E_i) · n_i
合格：N ≤ d_i ≤ M
展示偏差（可选）：e_i = d_i - target
```

d 是有向距离：胶越过工件边到另一侧时 d 为负，按超差判定。记录保存 d 原值，偏差 e 只用于展示。

界面名称为“工件边缘中心距”。基准取工艺认可的物理边缘（如翻边、板边），在示教时由人确认。

枪嘴标定和机器人 TCP 服务于搜索区域与运动控制，本模式的位置基准只来自工件。

## 2. 阶段 A：前提验证

阶段 A 的结论决定是否进入实施，以及第一版的具体参数。方法是采集现场代表图，用 LyFlow 已有的 `glue.station_calipers` 离线试测，不改生产链路。

| 验证项 | 通过标准 | 不通过时的方案 |
| --- | --- | --- |
| 工件边可见性 | 每个需检测的 Pose 检测图中，工艺边与胶同时可见 | 该 Pose 继续用示教中线模式；或评估换视角/换 Pose |
| 工件边检出稳定性 | 重复上下件、反光、轻微遮挡下，边缘检出率和拟合残差满足要求 | 增加与胶无关的定位特征（孔、角点），或调整光照 |
| 高度差与视差 | 工件边与胶顶高度差造成的距离误差小于公差的约 1/5 | 增加测量平面映射，单独立项 |
| 胶与工件边的关系 | 统计正常件胶近边到工件边的距离，确认胶覆盖工件边的频率 | 按第 3.4 节的覆盖处理规则调整参数 |
| 位姿变化范围 | 统计工件平移、旋转；旋转在 ±3° 内时沿示教法向测量的误差可忽略 | 超出时改为实测边缘法向（阶段 C） |
| 节拍 | 单图测量耗时满足节拍预算 | 缩小搜索带或减少测点 |
| 尺寸依据 | 有独立量具测得的中心距样本，用于评估绝对精度 | 只评估相对变化，精度承诺推迟 |

现有实拍评测的部分像素当量由名义胶宽推算，只适用于相对变化评估，见 [算法决策 A-3](../decisions/algorithm.md)。

## 3. 算法方案

### 3.1 现状

| 现状 | 位置 | 新模式的处理 |
| --- | --- | --- |
| `position` 为胶中心相对示教中线的横向偏移，`d = (lo + hi) / 2 × mmPerPx` | [taught.rs](../../src-tauri/src/vision/taught.rs) `parse_result` | 新模式改为胶中心减工件边 |
| 算法图为读图 → `glue.taught_path` → `glue.bead_width` | 同上 `plan` | 新模式增加工件边搜索节点 |
| 解析时检查输出中心在固定测点 2 px 内 | 同上 `parse_result` | 新模式改为检查工件边位置和拟合质量 |
| 判定先做中值滤波，短段 Invalid 被容忍 | [judge.rs](../../src-tauri/src/judge.rs) `filtered`、`MAX_INVALID_LEN` | 基准失败使用独立状态和容忍长度（第 5 节） |
| 多视图聚合优先取通过的视图 | 同上 `aggregate_views` | 第一版每 Pose 一张图；聚合沿用现策略，基准失败只挂帧徽标 |

### 3.2 流程

```text
当前完整图像
  → （可选）独立特征粗定位
  → 在每个示教测点上，沿示教法向：
       工件边搜索带 → 工件边点 E
       胶搜索带     → 胶两边 lo/hi、中心 B
  → 对工件边点拟合直线，得到残差与候选数（质量门）
  → 输出有向中心距、胶宽、各自状态与几何证据
  → GlueSight 按配方判定
```

### 3.3 测量方向与测点

第一版沿用示教中线的测点、站距和法向，只换位置基准：

- **测量方向**：使用示教法向。工件旋转 3° 时，4 mm 距离的误差约 0.005 mm，在验证过的旋转范围内可忽略。
- **工件边拟合**：同一段内的工件边点拟合一条直线，残差和候选边数量作为质量门：残差超限或出现多条相似候选边时，标记基准歧义。
- **测点身份**：测点 ID、名义弧长和站距保持配方原值，连续超差长度按名义站距累计，与现有判定一致。
- **沿边定位**：单条直边只确定法向位置。限值沿边恒定时直接测量；起止位置或区段限值依赖具体位置时，增加与胶无关的孔、角点等特征，经 `glue.locate` 粗定位后再测。

阶段 A 显示旋转超出范围时，再在阶段 C 改为用拟合边缘的实测法向。

### 3.4 搜索带与胶覆盖工件边

工件边和胶分别有自己的搜索带，都沿法向定义：

- **工件边搜索带**：以示教时确认的工件边位置为中心，宽度覆盖工件的位移范围；按灰度极性、最小对比度筛选。
- **胶搜索带**：从工件边点起，沿涂胶侧展开，范围覆盖 0 到 M 再加上需要检出的超差余量，保证超差的胶仍在搜索带内并按超差判定。
- **两带划分**：工件边优先在胶搜索带之外取点；示教时检查两带在正常件上不重叠。

胶离工件边较近时，胶可能局部盖住工件边。处理规则：

1. 段内仍有足够多的可见工件边点时，用可见点拟合的直线外推出被盖住测点的基准位置，照常计算 d。
2. 某测点的工件边缺失，且胶的近边已延伸到外推基准线上或越过它时，该点记为“胶覆盖工件边”，位置状态为超差（d ≤ 0），判定为 NG_POSITION。
3. 整段可见工件边点不足以拟合时，记为基准丢失，判定为 ERR_INSPECT。

阶段 A 统计正常件胶近边到工件边的距离，用来确定第 1 条的最少可见点数。

### 3.5 胶条测量

- 胶边检测沿用当前 `glue.bead_width` 的方法；阶段 A 对比 `station_calipers` 的胶检测，实拍对比更好时再替换。
- 胶边被图像边界或搜索带截断时，该点记为测量无效。
- 胶宽沿法向测量，第一版要求局部胶与工件边近似平行，胶宽定义与现有模式一致。
- 记录保留原始距离、工件边点、胶两边、中心、法向、拟合残差和状态，超差点照常保留以供追溯。

### 3.6 LyFlow 复用与分工

| 能力 | 现状 | 本方案需要补充 |
| --- | --- | --- |
| `glue.station_calipers` | 宿主给法向；分别搜索工件边（`innerSearch`）和胶（`beadSearch`）；输出中心距、胶宽、缺边/缺胶状态 | 有向毫米距离（`innerCenter` 现为无符号，`innerCenterPx` 有向）；段内直线拟合与歧义判断；覆盖状态 |
| `glue.locate` | 模板求二维平移和旋转，可变换测点和法向 | 需要沿边定位时使用，模板只取与胶无关的特征 |
| `glue.edge_distance` | 从胶向两侧找边、自动选侧 | 用于辅助对比，本方案的基准来自 `station_calipers` |

分工：LyFlow 负责像素算法和版本化输出；GlueSight 负责配方、图构建、结果解析、判定和业务流程。LyFlow 的修改单独立项，由其负责人实施。

## 4. 示教流程

1. **选图**：每个 Pose 选一张检测图，要求工件边和胶同时清晰。
2. **选择位置模式**：示教中线偏移 / 工件边缘中心距。
3. **示教胶中线**：沿用现有中线工具，确定测点、站距和法向。
4. **示教工件边**：在图上框选工件边，自动提取后确认；界面叠加工件边、两个搜索带和指向涂胶侧的箭头。需要沿边定位时另选定位特征。
5. **填写工艺距离**：输入目标值、下限、上限和允许超差长度。
6. **保存参数并试测**：显示当前帧的工件边、胶两边、中心和每点测距线；基准丢失、基准歧义、胶覆盖工件边、距离超差分别标示。
7. **保存示教 → 独立样本验证 → 发布**：沿用现有流程，承接上一步的有效试测。

新增字段接入 `ShotTeach`、草稿比较、视图切换、`saveParams`、`shot_tags`、进度和验证依赖。工件边、涂胶侧、搜索带或定位参数变化后，已有试测和验证结果失效。

界面按模式显示“示教线偏移 mm”或“工件边缘中心距 mm”；历史叠图显示当帧实测的工件边。[TrialResult.tsx](../../src/features/workspace/TrialResult.tsx) 的状态随新输出扩展。

## 5. 判定

| 情况 | 结果 |
| --- | --- |
| 工件边、胶有效，N ≤ d ≤ M | 位置 OK |
| 工件边、胶有效，d 越界 | 按限值和允许超差长度判定，超过为 NG_POSITION；超绝对限为 NG_ABSOLUTE |
| 胶覆盖工件边（第 3.4 节规则 2） | 位置超差，NG_POSITION |
| 工件边有效，胶搜索带内无胶 | 按断胶规则 |
| 基准丢失或歧义，连续长度不超过容忍长度 | 该段点记为基准无效，其余点照常判定 |
| 基准丢失或歧义，连续长度超过容忍长度；定位失败 | 该段位置判不了；整件只因此判不了时 ERR_INSPECT（faultCode 92），同一件另有 NG 时报 NG |
| 胶边截断 | 测量无效，按现有 Invalid 规则 |

判定参数复用现有配置：

- 位置限值继续用 `limits.position`（名义值、上下公差、绝对限、`max_excursion_len`）。
- 工艺要求任一点越界即不合格时，配置 `max_excursion_len = 0`。`filter_window` 当前为配方级参数，同时作用于胶宽；需要只对位置逐点严格时，再增加按任务的滤波窗口。
- 基准无效的连续容忍长度与胶测量共用 `MAX_INVALID_LEN`（2 mm），不另设常量；测不了与无基准交替出现时连起来算长度。

> 2026-10-21 更新：特征定位 G1 已按上述规则落地通用的“有胶、无位置基准”站状态（见 [p0-plan.md](p0-plan.md) 位置基准一条），本模式沿用，不再单独配置容忍长度。多视图沿用 `aggregate_views`：同一拍照点有一个视图合格即合格，另一视图基准失败只挂帧徽标。

基准失败原因贯穿适配层、cycle、离线、验证、历史复测和审计记录。PLC 沿用现有主结果码，细分原因只写入记录；新增 faultCode 需先按协议约定。

## 6. 配方与结果（草案，阶段 A 后定稿）

`positionReference` 属于拍照点/视图的几何配置，位置限值仍在 `limits.position`。以下示例仅说明结构，数值来自示教。

```json
{
  "positionReference": {
    "mode": "workpieceEdge",
    "edge": {
      "points": [[100, 120], [500, 160]],
      "beadSide": "left",
      "searchHalfMm": 3,
      "polarity": "darkToBright",
      "minContrast": 16,
      "maxFitResidualMm": 0.2,
      "minVisibleRatio": 0.5,
      "maxGapMm": 2
    },
    "localization": { "mode": "none" }
  }
}
```

- `beadSide` 相对工件边点序定义，界面用箭头显示；点序反转时同步翻转或要求重新确认。
- 启用定位时另存模板资源 ID、修订号、锚点、搜索范围和角度范围。
- 配置进入 `ShotSpec`、`ShotViewSpec` 和 `for_view`；必检条件增加工件边完整、搜索带有效、测点充分和标定适用。

| 模式 | d 的含义 | 示例 |
| --- | --- | --- |
| `taughtPath` | 胶中心相对示教中线的横向偏移 | 目标 0 mm |
| `workpieceEdge` | 胶中心相对指定工件边的有向距离 | 目标 4 mm，±1 mm，即 3～5 mm |

结果记录增加测量定义版本、`positionMetric`、`positionValueMm`、实测工件边几何，以及分开的 `referenceState`、`beadState`、`positionState`，基准失败时胶宽证据照常保留。

## 7. 格式、发布与历史

按 [AGENTS.md](../../AGENTS.md) 的 D-0，软件未正式投产，新格式直接替换旧格式：

- 显式升级配方 schema（当前 `RECIPE_SCHEMA = 7`）、测量契约和发布 schema（当前 `RELEASE_SCHEMA = 3`）；旧配方和发布包按项目规则提示后拒绝或备份重建。
- 保留示教中线模式，是指新格式中可以配置 `taughtPath`。
- 发布包冻结工件边几何、定位模板、测点、标定和算法版本；资源按 ID、修订号和结构/尺寸/路径校验。
- [store.rs](../../src-tauri/src/store.rs) 的 `measurement_layout` 纳入位置模式、工件边和定位参数，使跨模式的配方各自计算测量值。
- 历史重判：只改工艺阈值时按相同测量定义重判；测量定义改变时用原图重测，原图缺失时拒绝转换。旧记录的 d 保持“示教中线偏移”含义归档。
- 点 BLOB、审计 spool、详细 JSON 和快照的版本一起设计，字段确有变化时才升级数据库版本。
- 只改检测几何时 PLC planVersion 不变；拍照点、相机、Pose 或计划变化时按既有规则处理。

## 9. 测试计划（阶段 B）

优先通过公开的测量/判定入口验证业务结果；同类边界参数化，跨模块行为用少量集成测试。

| 条件 → 预期结果 | 保护的规则 |
| --- | --- |
| 工件与胶共同平移/旋转（验证范围内）→ 中心距稳定 | 共同运动不计入胶偏 |
| 工件不动、胶向两侧移动或越过工件边 → d 随之变化并按有向限值判定 | 基准独立于胶；错误侧判为超差 |
| 胶局部盖住工件边 → 外推基准后照常测；盖住且越过基准线 → NG_POSITION | 胶越边判为超差，而非检测异常 |
| 工件边整段缺失或歧义 → 该段 ERR_INSPECT（faultCode 92）；同拍照点其他视图 OK 时按 OK，只挂帧徽标 | 基准失败可见，多视图沿用 `aggregate_views` |
| 基准短段丢失不超过 2 mm → 其余点照常判定；超过 → ERR | 基准容忍长度复用 `MAX_INVALID_LEN` |
| 工件边有效、无胶或胶边截断 → 分别为断胶/无效 | 区分断胶与无法测量 |
| d 恰为 N/M、刚越界、短段越界 → 符合闭区间与允许超差长度 | 边界与滤波按配置口径判定 |
| 换图或修改工件边后试测 → 配置完整且旧试测失效 | 草稿保留、旧结果失效 |
| 跨模式重判 → 要求原图重测 | 两种 d 含义分开 |
| 旧格式配方进入新实现 → 提示后拒绝或重建 | 执行 D-0 |

现场验证补充重复上下件、正常补偿、真实胶偏、反光、遮挡、节拍和独立尺寸测量。

## 10. 其他待确认
