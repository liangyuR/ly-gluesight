# 以工件边缘为基准的胶条位置检测方案

状态：待实施、待现场验证。记录日期：2026-10-20。本次交付仅固化讨论和资料，不改变算法、配方或生产行为。

源码基线：GlueSight `c74a9f7926e365cea9b2ef6b735b70e5e7585e1b`；外部 LyFlow 调研基线 `5cefe3c75b227d138f1435ae7d6e7486b397926b`。以下源码链接用于定位事实，方案字段及新行为均为建议。外部资料与证据边界见 [方法与资料调研](../research/glue-position-methods.md)。

## 1. 目标与测量定义

现场希望判断胶条是否位于工件规定位置，例如胶条中心距离指定工件边缘 3～5 mm。新增“工件边缘中心距”模式，保留“示教中线偏移”作为可选测量方式。保留模式不等于兼容旧格式数据，格式策略见第 7 节。

每帧独立识别工件基准，再测胶。基准必须是工艺认可的物理边缘，不能只选画面中最明显的阴影或划痕。产品界面使用“工件边缘中心距”，不直接宣称实现了图纸意义上的几何位置度。

在有效测量平面内，令 `E_i` 为工件边缘点，`n_i` 为从该边指向允许涂胶侧的单位法向，`B_i` 为同一法向上的胶条两侧边缘中点：

```text
d_i = (B_i - E_i) · n_i
合格区间：N_i ≤ d_i ≤ M_i
可选展示偏差：e_i = d_i - target_i
```

`d` 保存有向实际距离，不减去目标值后再与距离上下限比较；不取绝对值使错误侧的胶变为合格。每段先使用统一的目标及上下限。

第一版适用条件：每个 Pose 组选一张检测图，同时看得到胶和一段局部直线工件边缘；工作距离、视角、测量平面在验证范围内。拐角、断裂及限值变化处分段，平滑曲线作为后续扩展。

枪嘴标定不是本模式的前置依赖。机器人 TCP 用于运动控制，相机与枪嘴标定可辅助搜索/遮挡处理，均不能代替工件位置基准。

| 已确认事实 | 证据入口 | 对新方案的影响 |

| `record.innerCenter` 实际存上述偏移 | 同上，`ShotMeasurement::record` | 字段名不能作为已有工件边距功能的证据 |
| 每 Pose 组选一张检测图；试测与保存示教分开 | [TeachingPage.tsx](../../src/features/workspace/TeachingPage.tsx)、[workflow.rs](../../src-tauri/src/workspace/workflow.rs) | 保持现有业务闭环，不扩展多视图配置范围 |
| 测量有效性与产品合格不同，NG 可以是有效试测 | [workspace.rs](../../src-tauri/src/workspace.rs)，`measure_image` | 不能要求放宽公差至 OK 才能保存测量配置 |
| 判定先滤波，短段 Invalid 可能被容忍 | [judge.rs](../../src-tauri/src/judge.rs)，`filtered`、`MAX_INVALID_LEN` | 基准缺失不能简单映射旧 Invalid |
| 通用多视图聚合优先接受通过视图 | 同上，`aggregate_views` | 必检基准失败不能被其他 OK 掩盖 |

当前模式在拍照点、姿态、触发位置足够重复时仍有用途。机器人补偿工件位姿且相机同步运动后，画面可能保持一致，不能仅凭“机器人补偿了路径”推断画面一定变化；应看实际图像。新模式解决的是在有效范围内直接测量工件与胶的相对关系。

## 3. 算法方案

```text
当前完整图像
  → 可选工件模板粗定位
  → 指定搜索带内提取工件边缘
  → 拟合当前边缘及局部法向
  → 沿工件法向搜索胶条两边
  → 输出有向中心距、宽度、有效性和几何证据
  → GlueSight 按配方判定
```

### 3.1 基准搜索与测点对应

- 搜索工件边独立于是否找到胶；约束搜索带、灰度极性、对比度、几何位置和连续性。不能让胶的位置决定选择哪一条工件边。
- 第一版拟合局部直线，用实测边生成法向。多条相似边无法唯一确认时报告歧义，不盲选最强候选。
- 工件位移/旋转较大时，先用与胶无关的孔、角点等模板作粗定位，再精测边缘。模板不得依赖胶条，否则可能把真实胶偏一起补偿掉。
- 单条直边只能约束法向位置和方向，不能唯一确定沿边平移。只测恒定区间的局部距离时可不定位纵向；若起止位置、断胶区段或区段限值依赖具体位置，必须增加端点/孔位/角点等独立约束。
- 保持配方 station ID 和名义弧长稳定，实际坐标随定位变化。不得按每帧检测数量重新编号；不能沿用“必须接近固定像素点”的解析校验，要改验变换、身份和几何合理性。

### 3.2 胶条搜索与尺寸

- 基准识别后，胶搜索带随基准移动。仅改距离公式、继续用固定像素窗口，不足以解决整体位移。
- 搜索范围必须覆盖允许位移及需要检出的超差，宽于验收区间 N～M。越界不能先被搜索过滤，再误报断胶。
- 沿基准法向取得近胶边、远胶边和中心；图边/窗口截断时不得补造另一条边。
- 标量像素当量仅用于已验证的平面和视角。透视明显时需要映射到测量平面后定义法向和距离；不能仅把图像法向上的长度乘一个常数。
- 工件边法向截面宽度未必等于胶条自身法向宽度。第一版限定局部胶与基准近似平行，并验证差异；若需要保留原有胶宽定义，保留独立胶宽测量通道，不能悄悄改变旧胶宽公差的含义。
- 保存原始距离、实测基准点、胶边、中心、法向、质量及失败原因。不能因为距离超出工艺公差就将其剔为离群点。

### 3.3 LyFlow 复用范围

调研源码提供了下列能力，但尚未接入当前 GlueSight 生产图；是否存在于实际随包 DLL、性能和质量是否合格，仍需验证。

| 能力 | 已有行为 | 需要补足 |
| --- | --- | --- |
| `glue.locate` | 模板求二维平移和旋转 | 使用独立工件特征，验证对反光、旋转和视角变化的适用范围 |
| `glue.station_calipers` | 独立 `innerSearch`/`beadSearch`；测内边到中心距离；输出缺边/缺胶等状态 | 当前法向由宿主提供；需当前边缘拟合、歧义判断、有向毫米距离及独立质量状态 |
| `glue.edge_distance` | 从已找到的胶向周围找边，自动选侧并剔除异常距离 | 不适合原样作为指定工件边基准：缺胶时基准不可独立确认，可能选错边或滤掉真实胶偏 |

`station_calipers` 的毫米 `innerCenter` 使用无符号距离，而 `innerCenterPx` 保留方向；不能直接沿用前者实现有向契约。其胶检测与当前 `bead_width` 不同，不应未经实拍比较就替换现有胶检测。

建议 LyFlow 负责像素算法和版本化输出契约，GlueSight 负责配方、图构建、结果适配、判定与业务流程。先用已有算子验证可行性，正式实现优先复用基准搜索/位姿和已验证的胶边检测核心。本方案不授权直接修改其他任务负责的 LyFlow 工作区。

## 4. 示教流程

1. **选图**：继续每 Pose 一张检测图，必须同时看清工件基准和胶。看不到基准时不能静默使用枪嘴或胶边替代。
2. **选择位置模式**：示教中线偏移 / 工件边缘中心距。
3. **示教基准边**：框选或刷选边缘，自动提取后确认；叠加基准、搜索带和胶侧箭头。需要纵向定位时另选工件特征模板。
4. **示教胶搜索区域**：复用胶中线工具作为搜索种子；新模式下不再把它当作位置零线。
5. **填写工艺距离**：输入目标、下限、上限和严格/允许短段超差规则；不能从正常样本自动推导并覆盖工艺标准。
6. **保存参数并试测检查**：显示当前工件边、胶两边、中心、法向测距线和逐点数值；基准丢失/歧义与距离超差分别显示。
7. **保存示教、独立验证、发布**：承接上一步的有效试测，不要求重复试测。完整顺序为保存参数→试测→保存示教→独立样本验证→发布。

新字段必须进入 `ShotTeach`、草稿比较、视图切换、`saveParams`、`shot_tags`、进度和验证依赖。基准/胶侧/模板/搜索参数变化后，旧试测及验证失效；不能仅增加表单而漏掉保存链路。

界面按模式显示“示教线偏移 mm”或“工件边缘中心距 mm”；历史叠图显示实测基准，不用示教基准冒充当帧测量依据。现有 [TrialResult.tsx](../../src/features/workspace/TrialResult.tsx) 只接受有限状态，需要随新输出扩展。

## 5. 配方和结果契约建议

`positionReference` 属于拍照点/视图几何配置，位置限值继续由 `limits.position` 承载。以下 JSON 仅演示结构；坐标和阈值不是现场默认推荐值，具体 schema 在实施时定稿。

```json
{
  "positionReference": {
    "mode": "workpieceEdge",
    "reference": {
      "geometry": "line",
      "points": [[100, 120], [500, 160]],
      "beadSide": "left",
      "searchHalfMm": 3,
      "polarity": "darkToBright",
      "minContrast": 16,
      "maxFitResidualMm": 0.2
    },
    "localization": { "mode": "none" }
  }
}
```

胶侧相对于有向参考线定义；界面必须画箭头，反转点序时显式保持物理胶侧或要求重新确认。定位启用时另存模板资源 ID/版本、锚点、搜索范围及角度范围。

新增配置同步进入 `ShotSpec`、`ShotViewSpec` 和 `for_view`；必检条件增加基准完整、搜索区域有效、测点充分及标定适用性。新模式的测点来源与解析契约单独版本化，不强行套用旧 path 重采样检查。

| 模式 | d 的含义 | 示例 |
| --- | --- | --- |
| `taughtPath` | 胶中心相对示教中线的横向偏移 | 目标 0 mm |
| `workpieceEdge` | 胶中心相对指定工件边的有向距离 | 目标 4 mm、下差 1 mm、上差 1 mm，即 3～5 mm |

记录增加测量定义版本、`positionMetric`、`positionValueMm`、实测几何和基准失败原因。原始距离与展示偏差分开；`referenceState`、`beadState`、`positionState` 概念分开，避免基准失败吞掉仍有效的胶宽证据。

测点 ID、名义弧长及连续超差长度口径保持明确。第一版仍按配方名义站距累计长度；曲线扩展时不得静默改成另一条线的弧长。

## 6. 判定与失败处理

| 情况 | 预期处理 |
| --- | --- |
| 基准/胶有效、距离在闭区间内 | 位置 OK |
| 基准/胶有效、距离越界 | 严格策略下 NG_POSITION；启用短段超差容忍时按配置判定，绝对限仍按明确规则处理 |
| 基准有效且完整搜索区域内无胶 | 按断胶规则，不归为基准丢失 |
| 基准丢失、候选歧义、定位失败 | ERR_INSPECT，给出具体原因 |
| 胶边或搜索区域被截断 | 测量无效，不补边、不默认合格 |
| 错误侧胶被测得 | 使用有向距离判超差；不可取模后合格 |

第一版建议必检站基准全部有效才允许位置任务通过。基准失效不能仅映射现有 Invalid，因为现有逻辑容忍短段无效。显式失败原因须贯穿适配层、cycle、离线、验证、历史复测和审计，不能一律归类为处理超时。

当前配置流程只选一检测图，第一版不扩展多视图业务；通用聚合仍需保证必检位置任务错误不会被其他 OK 覆盖。后续若支持多视图，先定义是替代视图还是不同必检区域，再确定聚合策略。

若 N～M 表示任一有效点越界即不合格，新模式默认原始有效距离判定、允许超差长度为 0；图表可以另作平滑但不得影响该规则。当前全局中值滤波不能直接沿用成严格逐点判定。若开启连续超差长度容忍，须在配方明确记录；不能把所有误差都交给放宽公差处理。

现有 PLC 主结果码可优先复用；具体基准失败原因保存在记录中。是否新增细分 faultCode 必须按协议约定，不能未经协议核对修改现场含义。

## 7. 发布、格式与历史

本次将讨论中“增加旧格式兼容读取”的建议修正为遵循当前 [AGENTS.md](../../AGENTS.md) 的 D-0：软件尚未正式投产，不新增旧格式读取兼容。保留旧测量模式，是允许在新格式中明确配置 `taughtPath`，不是自动迁移旧配方/记录。

- 实施时显式升级需要改变的配方、测量契约和发布图版本；旧格式按项目规则拒绝或备份后重建，先提示失效范围。当前 RECIPE_SCHEMA 为 6，发布 schema 为 2，不能只改常量就宣称迁移完成。
- 原始历史证据可归档保留，但不把旧 d 重解释为新中心距，也不把旧胶中线自动当工件基准。
- 发布包冻结基准几何、模板、测点、标定和算法版本；资源用 ID、修订号、实际字段和结构/尺寸/路径校验，不引入内容哈希匹配。
- 修改基准模式/几何/定位参数须重新试测、验证和发布；只改工艺阈值可在相同测量定义下重判，改变测量定义必须用原图重测，无原图就拒绝转换。
- [store.rs](../../src-tauri/src/store.rs) 的 `measurement_layout` 必须纳入模式、基准和定位参数，防止跨模式复用测量值。
- 点 BLOB、审计 spool、详细 JSON 和快照的版本应一起设计。现有数据库版本不匹配会进入备份重建流程，实施前须明确触发范围；不为增加界面字段无理由升级数据库。
- 仅改变检测几何不改变 PLC planVersion；实际拍照点、相机、Pose 或计划发生变化时才按既有规则处理。

阶段 A：采集现场代表图及独立尺寸依据，验证能否稳定识别工艺边、能否定位区段，比较已有卡尺与当前胶检测，测耗时；先验证实际随包引擎能力。

阶段 B：实现单检测图、局部直边、明确胶侧、可选粗定位、中心距限值和完整失败追溯的闭环。发布前重新验证已有胶宽/断胶能力。

阶段 C：按实际需求增加曲边、多区段和测量平面映射；高度/倾角变化明显的场景需单独方案。当前工作不实施这些阶段。

## 9. 验收与测试准入计划

以下是实施阶段的计划，不是已执行测试。优先通过公开测量/判定入口验证业务结果；同类边界参数化，跨模块行为以少量集成测试覆盖。

| 条件 → 预期结果 | 保护的规则 |
| --- | --- |
| 工件和胶共同平移/旋转且在有效范围内 → 中心距稳定 | 不将共同运动误判为胶偏 |
| 工件不动、胶向两侧移动或越过基准 → 距离改变并按有向限值判定 | 不跟着胶移动基准、不取绝对值掩盖错误侧 |
| 必检基准遮挡/缺失/歧义 → ERR，其他 OK 不覆盖 | 不因短段 Invalid 容忍或通用聚合错误放行 |
| 基准有效、无胶或胶边截断 → 分别得到缺胶/无效 | 不混淆断胶与无法测量 |
| 值恰好等于 N/M、刚越界或短段越界 → 符合闭区间及严格策略 | 边界及滤波不改变验收口径 |
| 换图或修改基准再试测 → 配置完整且旧结果失效 | 防止草稿丢失、旧试测复用 |
| 新格式内跨模式申请重判 → 要求原图重测 | 不将示教线偏移当作工件边距 |
| 旧格式进入新实现 → 明确拒绝/重建提示 | 执行 D-0，不静默转换测量含义 |

现场验证须补充重复上下件、正常补偿、真实胶偏、反光、遮挡、节拍和独立尺寸测量。现有实拍评测的部分像素当量由名义胶宽推算，仅能验证相对变化，不能证明绝对中心距精度，见 [算法决策 A-3](../decisions/algorithm.md)。

## 10. 实施前待确认

- 每个检测区段具体使用哪条工艺边，圆角/宽边取哪一个物理位置；是否每张图都看得到。
- N～M、目标值及是否允许短段超差；要求是局部法向距离，还是图纸另有尺寸定义。
- 现场平移、旋转、工作距离、倾角、曝光模糊范围和精度目标。
- 是否需要沿边区段定位；若需要，是否存在与胶无关的唯一特征。
- 基准边与胶顶是否存在不可忽略的高度差和视差；二维测量是否足够。
- 严格基准有效性要求造成的拒检率，以及节拍预算。

同帧相对测距仅在成功识别、方向正确且标定适用时抵消共同平移/平面旋转；不会自动消除高度、透视、视差、错边或区段对应错误。
