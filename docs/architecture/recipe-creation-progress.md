更新时间：2026-10-11。工作分支：`codex/recipe-capture-workflow`。

本轮按 [配方创建与多图示教](recipe-creation-workflow.md) 完成软件实现和收尾。负责人明确本轮无需现场验收、忽略算法；设备接线、真实精度、算法质量与持续运行现场验收不作为本次交付条件。已有中线提取和引擎接口保留，不在本轮调优算法。

## 实现范围

| 模块 | 交付行为 |
|---|---|
| 空草稿与进度 | 新建空配方；进度页恢复上次点/图位置；草稿保存与示教完成分别表示 |
| 整圈采集 | 单 device 一次触发交付拼接原图及三幅分图；1–64 点；等待 PLC 结束及 200–30000 ms 在途收图 |
| 来源保护 | 检查可验证计数基线、会话、连续帧号、触发计数、数量与尺寸；异常轮次保留；所有来源失败后必须重新连接设备建立新会话，防止迟到旧帧混入重采 |
| 多图示教 | 每点选择 1–3 图，分别保存中线、比例、参数、试测及完成状态；有效 NG 可完成；取消重选保留有效示教；默认参数仅失效实际受影响的图 |
| 标定状态 | 按 device 和图编号保存引用；兼容当前标定 JSON 的嵌套 data.mmPerPx；重新标定同步继承比例、保留人工覆盖；代表点复用须人工确认且条件一致 |
| 重采与恢复 | 人工确认点数、轨迹和顺序一致后继承为待确认草稿，保留人工比例覆盖；已采用整圈的候选禁止单帧采集、导入或恢复替换来源 |
| 判定接口 | 同点多图 OR、整件异常优先；保留各图独立结果及异常；全不检不能发布 |
| 独立样本 | 禁止示教轮次自证；独立整圈和适用历史完整原图重测；核对非零 PLC 计划版本及结构；旧每点单图导入不用于整圈多图候选 |
| 冻结发布 | 不可变包、工件及 PLC 事务边界切换；冻结期间前后端拒绝编辑或新采集；失败保留同一版本重试；生效状态不确定时阻止下一件 |
| 集成脚本 | 演示配方、桥和校验器更新到结构版本 5、camera-vN 标定引用，保留多图配置参与契约比较 |

配方结构版本 5、发布包版本 2。按 D-0 拒绝旧结构；使用明确 ID、修订号、版本、轮次、点及图编号，不增加业务内容哈希匹配。
