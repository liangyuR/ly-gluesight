# 运行日志与视觉证据存储

运行日志、PLC 通讯日志和历史原图集中存放在 `~/gs_logs`；配方、示教、标定、采集轮次、发布资源和历史数据库继续随 project 保存。`~` 由程序解析为首次初始化时运行账号的用户主目录。

## 目录与归属

```text
~/gs_logs/
├─ runtime/<环境>/<资料实例>/
│  ├─ gluesight-YYYY-MM-DD[.N].jsonl
│  └─ plc.db
└─ vision/<环境>/<资料实例>/<项目编号>/
   ├─ records/
   └─ records-offline/
```

环境为 `production`、`development` 或 `test`。资料实例是首次生成并持久保存的 16 位十六进制标识，不同资料目录即使使用相同项目编号，也不会混用外部原图。运行日志按环境和资料实例汇集，视觉证据再按项目、真机与离线来源隔离。

资料根目录仍为正式版 `%ProgramData%/ly/GlueSight` 或开发版 `%ProgramData%/ly/GlueSight-dev`。开发/测试显式指定 `GLUESIGHT_DATA_DIR` 时，日志根为该隔离目录下的 `gs_logs/`，不写入日常用户日志目录；安装版仍拒绝该覆盖变量。

首次初始化把绝对日志根、环境、资料实例标识与规范化资料根 `ownerData` 保存在资料根的 `config/log-storage.json`。以后沿用该绑定；换 Windows 账号不会自动改写日志根或另建一份历史原图。复制或搬迁整份资料目录后，不能直接沿用原绑定，避免两个副本共用并清理同一批原图。绑定目录不可用、权限不足、环境不符或命名空间已被占用时阻止业务启动，需修复原因后重试。运行实例持有该命名空间的独占锁，资料目录锁仍保留。

本次不提供界面修改日志根。调整目录需要同时迁移文件及受管引用，不能只编辑配置中的路径。

| 内容 | 位置 | 生命周期 |
| --- | --- | --- |
| 程序日志 | `runtime/<环境>/<实例>/gluesight-*.jsonl` | 按时间和容量滚动；事件带 `sessionId`，打开项目后带 `projectId`，旧日志仍可读 |
| PLC 日志 | 同一 runtime 目录下 `plc.db` | SQLite；运行时可有 WAL/SHM，保留天数来自当前 PLC 配置 |
| 真机历史原图 | `vision/<环境>/<实例>/<项目>/records/` | 按当前项目的真机录制策略保留 |
| 离线历史原图 | 同项目外部目录下 `records-offline/` | 独立录制和清理，不挤占真机原图 |
| 历史数据库 | 项目内 `inspection.db` | 按项目隔离，保留录制状态与外部原图引用 |
| 整圈采集原图 | 项目内 `recipe-capture/<轮次>/` | 示教、多轮标定与验证资产，不按历史原图策略清理 |
| 冻结示教图与标定特征 | 项目内 `workspaces/<配方>/images/`、`calibration/<轮次>/` | 随候选、项目和配方迁移包保存 |
| 棋盘格标定结果与原图 | 项目内 `calib/`、`calib/images/` | 成功标定写入原图及项目相对引用，随项目迁移 |
| 发布资源 | 项目内 `vision/releases/` | 不可变发布资源，包含冻结示教图和标定引用，不属于视觉日志 |
| 恢复状态及审计 | 本机 `state/`、项目内 `audit-spool/` | 维持现有恢复契约，不归入普通日志清理 |
| 受管离线样本 | 资料根下 `samples/` | 候选调试可直接引用，不重复录制 |

录制原图内部结构保持日期目录、`*_cycle_<cycleId>/`、`{相机}_s{seq:06}.pgm` 和 `part.json`，不改变相机与帧组身份。

## 启动迁移

在运行日志、PLC 日志库和检测服务启动前，程序准备绑定的日志目录并迁移旧数据：资料根的 `logs/` 进入 runtime，各项目原有 `records/`、`records-offline/` 进入对应的外部项目目录。

迁移先预检目标空间，复制到暂存区并核对字节数及 SHA-256；PLC SQLite 日志库使用 `VACUUM INTO` 生成包含 WAL 的一致性快照并检查完整性。目标已有不同内容时拒绝覆盖。旧日志和原图副本保留，不自动删除。

外部文件就绪后，重定位项目数据库的 `recording_directory` 和审计 spool 中明确的录制目录引用，写入 `.legacy-import.json` 完成标记后清理暂存区。未完成的暂存清单支持中断后继续；完成标记阻止再次导入旧副本，因此新目录清理过的原图不会在重启时被旧文件复活。

迁移逐项目完成。若后续项目失败，业务服务不启动，已完成项目仍指向新目录，下次按标记继续；不承诺所有项目全局回滚，也不自动回退到旧根继续产生数据。旧副本的后续清理需要明确确认，不能误删项目内已经选用的图片。

## 历史读图、清理与磁盘空间

历史原图根据记录来源选择当前项目的真机或离线录制根，继续检查路径边界、`cycleId`、相机、帧组、帧号与 `part.json` 身份，不用任意同名文件代替。

运行日志保留 30 天、总量上限 1 GiB、单段上限 16 MiB，只清理 `gluesight-` 文件。历史数据库默认保留 180 天，真机原图默认 100 件/20 GB，离线原图默认 300 件/10 GB，均由当前项目设置控制。原图清理保护最新一件、在用及待入库目录，并同步数据库引用；带 `maintenance-collect` 标记的维护采集原图仍跳过自动滚动清理。

磁盘空间守护同时检查项目目录和外部原图所在目录，空间低于现有下限时暂停接件，提示包含对应目录。查询失败的处理沿用原有规则。示教、标定、采集轮次、样本和发布资源不进入原图滚动清理。

## 示教和标定图片

从历史选用一件用于示教或标定时，将原图物化到项目的 `recipe-capture/`：同卷优先硬链接，只有跨卷错误才改为复制并核验 SHA-256；权限等其他错误直接返回。失败撤回未完成轮次，不修改源录制。物化成功后，历史原图被清理也不影响项目轮次。

棋盘格标定成功时，原图保存到 `calib/images/<样本ID>.pgm`，标定 JSON 的 `samplePath` 为项目相对路径，另保留 `sampleId`、相机和视图。未显式冻结样本、直接使用最近帧时生成独立样本编号。先完成原图写入，再更新标定结果；图片写入失败时不发布新引用，已有图片不可被不同内容覆盖。同一冻结图像可复用原图后重新标定。

成功标定的样本图保留在项目内，本次不增加自动清理；标定页的临时冻结样本仍为内存对象，持久化的是成功结果所用原图。

## 项目管理与导出

项目 ZIP 格式继续使用 `project/records/`、`project/records-offline/`。勾选包含历史记录时，导出从外部目录收集原图，对数据库做一致性快照，并把快照中的外部路径归一到包内项目根。导入和复制时核验原图、重定位到新项目的外部目录；既有目标目录拒绝覆盖，操作失败撤回本次创建的外部资料。

导入和复制的外部原图带项目提交标记。启动恢复时，项目目录尚未提交则清理未完成原图；项目已提交则保留原图并移除标记，避免中断留下孤儿目录或误删已导入图片。

不包含历史记录时，示教图、标定图、采集轮次和发布资源仍完整随项目保存。项目用量分别报告项目目录和外部视觉证据，合计为占用空间；保留的旧目录副本仍占实际磁盘空间。

删除项目的确认范围包含该项目的外部视觉原图。项目先进入 `.trash`，持久化清理标记只记录项目编号；清理时核对编号与目录名，并通过受管配置推导外部路径，不信任任意文件路径。删除中断后启动续清，不清理其他项目或共用运行日志。

诊断包通过当前日志和录制根解析文件，包内结构保持原契约。系统设置显示资料目录、日志根、运行日志及当前项目视觉目录，并提供对应的打开入口。

## 验证边界

定向回归覆盖旧日志 WAL 快照、录制原图及引用迁移、冲突拒绝与重试、完成标记防重复导入、资料实例隔离与锁、外部盘空间守护、历史件跨卷物化、棋盘格原图保存、项目导出导入复制及删除续清。测试使用临时目录，不迁移开发或正式现场资料。

目录调整不替代真实相机、PLC 和现场磁盘吞吐验收。部署前应关闭旧实例，预留复制所需空间；迁移完成后通过设置页核对新路径，再检查既有记录和项目资产。

## 代码入口

- [`log_storage.rs`](../../src-tauri/src/log_storage.rs)：根绑定、环境及实例隔离、锁和启动迁移。
- [`storage.rs`](../../src-tauri/src/storage.rs)、[`cycle.rs`](../../src-tauri/src/cycle.rs)：资料状态、目录入口及录制根接线。
- [`applog.rs`](../../src-tauri/src/applog.rs)、[`plc.rs`](../../src-tauri/src/plc.rs)：运行日志与 PLC 日志。
- [`recorder.rs`](../../src-tauri/src/recorder.rs)、[`disk_guard.rs`](../../src-tauri/src/disk_guard.rs)：清理保护及项目/录制盘空间。
- [`recipe_capture/burst/history.rs`](../../src-tauri/src/recipe_capture/burst/history.rs)、[`vision.rs`](../../src-tauri/src/vision.rs)：历史件物化及标定图保存。
- [`project/transfer.rs`](../../src-tauri/src/project/transfer.rs)、[`project/manage.rs`](../../src-tauri/src/project/manage.rs)：项目打包、复制、统计与删除。
