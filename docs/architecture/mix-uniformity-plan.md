# 双组分胶混胶色差检测

现场将黄色与蓝色组分混合后涂胶，合格胶条呈绿色。检测目标是找出混合不良：细黄纹、细蓝纹、色斑，以及配比漂移造成的整段偏黄或偏蓝。检测项与报警都叫“混胶色差”，报警带偏黄或偏蓝的方向，操作员可在原图上复核位置。原生算子与 Python 参考使用同一组合成工件验证；GlueSight 中的混胶报警仅在 PC 侧记录，工艺公差和实物检出能力待现场验证。

## 设计要点

只示教合格绿胶，再各采一次纯黄和纯蓝组分用来定轴，不采集缺陷样本。

- **混合轴。** 黄、绿、蓝三种胶色在对数色度平面上连成一条折线：纯黄—合格绿—纯蓝。每个像素算两个量：
  - **轴向偏移**：沿折线的位置，合格绿为 0，纯黄为 −1，纯蓝为 +1。这是缺陷信号，符号即偏黄或偏蓝。它不是配比，也不是标准色差 ΔE。
  - **离轴量**：到折线的距离，用合格样本的离散程度归一。高光发白、薄胶膜透出底材、去马赛克彩边预期主要落在这个量上，不参与色差判定。
- **胶面由离轴量确定。** 离轴量小、亮度可用的像素算胶面，不论它偏黄、偏绿还是偏蓝。整段未混合的纯色胶因此报色差，不报不可测。现有“像绿胶”的得分会剔除异色像素，不用作胶面范围。
- **沿胶路拉直后量测。** 混合不良的条纹通常沿胶路延伸。把胶面沿胶路拉直成条带，沿胶路方向平滑、横向保持原图分辨率，压住像素噪声和彩边，横向相邻的黄纹与蓝纹不会被平均成绿色。
- **两类缺陷分开统计。** 细纹和色斑按连通区域的长度与面积判；配比漂移时每个像素只偏一点、连不成区域，按各测站轴向偏移的中位数判。
- **成像漂移单列。** 光照或白平衡变化与整段偏色在胶面上表现相同，用走廊两侧背景的色度区分：背景同时偏移时记“成像漂移”，该帧色差不可测。

特征沿用胶色测量的对数色度。[现有胶色测量](../decisions/color.md)

## 算子接口

lyFlow 只量测，门限都是参数；色差判定在 GlueSight。[测量与判定分工](../decisions/lyflow-operators.md)

| 算子 | 输入 | 输出 |
| --- | --- | --- |
| `glue.mix_model` | 多件合格彩色帧上的胶面取样与两侧背景取样；该相机的纯黄、纯蓝取样 | 带版本的模型：混合轴折线、轴向与离轴的离散程度、背景色度、有效样本数、取样帧的白平衡 |
| `glue.mix_map` | 生产彩色帧、模型、检测区域 | 与原图坐标对齐的轴向偏移图、离轴量图、有效性图（可测胶面、高光、过暗、离轴、区域外），以及与 `glue.color_map` 同格式的胶面得分图 |
| `glue.mix_regions` | 上述各图、胶路、搜索半宽、沿胶路平滑长度、轴向偏移门限 | 每个连通异常区域的方向、原图轮廓、沿胶路起止、横向宽度、面积、确认长度与含不可测空缺的跨度；各测站的轴向偏移中位数、胶面像素数与可测比例；背景色度偏移 |

长度和面积以原图像素为单位输出，GlueSight 按该相机的像素当量换算为 mm 和 mm²。生产路径只读取区域与测站量测，三张图在试测和流程调试时读取。

## 前置：成像

- **锁定白平衡。** 彩色海康相机在 Bayer 模式下关闭自动白平衡、回读三通道增益；相机页可保存当前白平衡供重连使用。录制件用 `devices[].imaging.whiteBalance` 留存有效回读。缺少回读的录制件不可用于拟合。现场首批采样前还须用当前相机、光源与 Bayer 输出确认通道增益的实际作用。[成像参数约定](../decisions/ui-recipe.md)
- **最小必检条纹的像素宽度。** Bayer 相机每种颜色隔一个像素采样一次，条纹横向少于 4 个原图像素时色度会被冲淡。按现场像素当量换算工艺要求的最小条纹宽度，不足时先调整视野或镜头。
- **高光。** 高光下面没有颜色信息，那里的色差测不出来。不可测胶面占比过高的段先调低曝光；仍不够时在光源和镜头上加正交偏振片。

## 实施计划

进场前的交付目标是一套可安装的现场联调版本。使用合成 Bayer 工件完成第 2、3 步的软件开发和端到端验证。现场样件用于验证成像与算法假设、优化参数、确定生产报警公差，并完成第 4 步验收。

进场前按以下结果验收软件：

1. 三个算子在实际随包加载的 lyFlow DLL 中注册。用相同的合成原图、胶路和参数对照 Python 参考结果，验证方向、有效性、缺陷尺寸及测站曲线。GlueSight 升级运行库时用已有配方回放胶宽、断胶与胶偏，核对已有算子的接口和结果。
2. 操作员可以完成按相机采端点、按段示教、配方试测与发布。在应用中用合成工件跑通逐帧测量、PC 侧判定、历史落库与原图复核；复测可追溯使用的模型版本。旧配方默认关闭混胶色差。模拟数据显式标注来源，正式采样仍要求有效的白平衡回读。
3. 现场安装包支持从第一批实物原图重新拟合并回放。模拟 PLC 可验证现行协议的登记与结果回传；色差专用结果码及多项 NG 的优先级按双方确认的协议另行联调。

### 1. 离线验证可行性

离线工具从原始 Bayer 录制件拟合模型，导出原图、轴向与离轴量、区域轮廓、测站中位数及背景偏移。有色胶面和裸露底材可分别标注，用于评估不可测比例和底材误入胶面的比例。合成工件可用于复核软件行为，现场通过判据需要独立实物样件。[命令与标注格式](../testing/TESTING.md#混胶色差的离线验证)

- **样件**：纯黄、纯蓝排胶各一次；由工艺人员在原图上标出刚好必须报警的黄纹和蓝纹，记录最细宽度与沿胶路长度；跨批次的合格件，含强反光与紧邻底材的位置；条件允许时做几档已知配比的手混样，把轴向偏移对应到配比偏差。以工件为单位划分拟合、调参和独立验收集，同一条纹的相邻帧归入同组。
- **现场算法通过判据**。每项均用实物样件核实；未满足的项记录原因，调整成像或算法后重测，再评估生产报警是否可启用：
  - 临界条纹与合格绿胶在平滑后的轴向偏移上能分开，整段偏色与合格批次间的差异在测站中位数上能分开；
  - 高光边缘、薄胶膜和胶边彩边的像素主要落在离轴量上，轴向分量不足以触发门限；
  - 纯黄、纯蓝胶面能由离轴量确认为胶面，裸露底材不被算作胶面；
  - 背景色度足以区分成像漂移与整段偏色。发黑铸件等色度不可靠的背景不满足时，改用固定在胶嘴支架上、始终在视野内的中性参考块；
  - 不可测胶面占比在工艺可接受的范围内。
- **里程碑**：一组原图、轴向偏移图与轮廓叠图，同一个模型在独立工件上圈出临界黄纹和蓝纹、标出整段偏色的测站，并把高光标为不可测。记录遗漏、误报和成像分辨率的限制。
- **高光假设不成立时的替代**：改用合格色的马氏距离作偏离得分，扩大高光掩膜，方向由区域平均色度相对合格绿的偏移给出。算子接口不变。

### 2. 实现和发布 lyFlow 算子

- 联调使用 lyFlow 2.0 系列。原生候选 2.0.4 提供三个混胶算子，GlueSight 使用 2.0.3 客户端并从实际加载的 DLL 校验必需算子。合成对照包括完整像素有效性、轴向和离轴量、轮廓、尺寸、背景及逐站结果。[lyFlow 依赖约定](lyflow-dependency.md)
- 算子回归只覆盖以下行为：
  - 横向相邻的黄纹与蓝纹各自成为区域，不被平均成合格色；
  - 贴着胶边的异色留在胶面范围内；
  - 高光两侧的条纹不被连成一个确认长度，跨度单独给出；
  - 整段纯黄的胶面输出偏黄测站，而不是无胶面；
  - 胶面与背景色度同向偏移时输出背景偏移，供宿主识别成像漂移。

### 3. 接入 GlueSight

- **配方与示教。** 按“相机 × 段”启用“混胶色差”，旧配方和旧发布包没有这一项即关闭；胶宽按灰度测量的段也可以启用，前提是相机为彩色模式。[配方创建流程](recipe-creation-workflow.md)
  - 混合轴的纯黄、纯蓝端点按相机采一次，用 Software 单帧拍排胶样；合格绿的中心、离散程度和背景色度按“相机 × 段”拟合。
  - 合格样本从历史件选择器里勾选的多件合格件自动取样，取每帧已测得的完整胶边之间、向内收缩的范围，操作员在叠图上确认后冻结。只有一件合格件时可以拟合，界面提示批次覆盖不足。
  - 模型不随走廊点修改而作废。测量时核对帧与模型的相机序列号、白平衡及合成／实拍来源，无法核实时记不可测。曝光与增益可在示教页核对。换胶批次或改光源后重新拟合。
  - 发布就绪检查列出已启用但缺模型、缺像素当量或图像模式不是彩色的项。
- **测量。** 发布包的 `graph.json` 为启用的相机和段冻结模型、`mix` 测量模板及参数，定向段还冻结 `mix_retrack`。示教走廊段直接使用走廊折线；定向段使用本帧拟合胶路，失败时用胶面得分图重试一次，仍失败记不可测。未启用的配方没有混胶图项。
- **判定。** 逐帧判定，跨帧不累加：帧在胶路上的位置目前只有胶路导航图按段内均匀插值的估计，不足以去重（[RB-9 工件胶路导航图](../decisions/recipe-build-flow.md#rb-9-工件胶路导航图)）。尺寸门限因此不超过单帧测量区间。
  - 细纹与色斑：单个区域的长度或面积达到门限即报。高光空缺两侧同方向、空缺短于合并门限时按跨度计，否则按确认长度计。
  - 整段偏色：测站中位数连续超限的长度达到门限即报。
  - 尺寸门限是业务参数，按 mm 存在配方里；轴向偏移门限、平滑长度和合并门限是模板门限，取模板默认值、随 GlueSight 发版。
  - 已有的超限证据保留；其余位置按可测比例记录完整性，成像漂移和不可测不计为色差，整件结论接入现有质量汇总规则。[站级证据口径](wide-bead-measurement-plan.md)
- **证据。** 记录相机、段、帧、方向、区域轮廓、尺寸、测站中位数曲线与模型版本。试测和历史复核定位到原图，区分偏黄、偏蓝、不可测与成像漂移。

单帧证据随 `FrameMetrics.mixEvidence` 保存，未启用时省略。原图轮廓和测站采用原图像素坐标；色斑面积乘像素当量的平方，条纹跨度及测站区间乘像素当量。沿胶路连续中位数超过同一方向门限才累计，缺观测或变向即中断。进场前联调模板将测站门限设为 0.16，背景归一偏移门限设为 3.5；这些值来自合成样例。背景显著偏移且其色度向量与胶面整体偏移方向一致时，该帧保留观测并标为成像漂移。背景无法测量时保留不可测原因。

区域结果的 `mixAlarmGroups` 可直接定位报警帧组，整件的 `flags.mixAlarm` 汇总 PC 侧混胶报警。生产跳过的帧只供诊断；常规判定及传给 PLC 的结果码沿用现行规则。历史概览只传色差状态和方向，打开单帧可查看当时记录的轮廓、尺寸、模型编号与各站中位数曲线。

- **通信。** 生产协议 9 的结果码 11–14 已分别用于位置、绝对值、断胶和胶宽。混胶色差需要新的结果码，并约定多种 NG 并存时的优先级；先修订协议文档并与现场确认，此前只在 PC 侧记录，不影响回给 PLC 的结果码。[PLC 结果码契约](../integration/plc-communication-protocol.md)

### 4. 独立验收与现场影子运行

验收线在独立验收之前由工艺方确定：最小必检条纹的宽度与长度、整段偏色的限度、允许的误报和不可测占比。冻结模型与全部门限后，在留出的工件上统计临界黄纹与蓝纹的检出数／标注数、整段偏色件的检出数／件数、合格件误报数／合格件数，以及不可测胶面占比。贴边细纹、强反光和跨批次合格件单列。

现场先随生产采图并记录结果，不报警。复核每次记录的图像、位置和尺寸，按实际相机数与帧率记录单帧耗时和测量队列积压。检出、误报、可测范围、节拍和 PLC 契约都确认后，再启用生产报警。

## 现场联调操作

1. **准备相机。** 保持生产用的视野、照明、曝光和增益，在相机页选择彩色模式，确认白平衡三通道回读并保存重连设定。首次进场先验证不同通道设定对实际 Bayer 像素的作用。
2. **采两种排胶样。** 等在途工件结束，把该相机切到 Software 单帧触发。在候选配方的“分段与示教”页选择相机和段，启用“混胶色差”，等候选保存后打开“示教混胶色差”。在纯黄排胶样放好后点击“Software 拍摄排胶样”，在冻结原图上拖框选胶面，点击“框选为纯黄”。换纯蓝排胶样，重新拍摄和框选，保存纯蓝端点。两种端点按项目与相机保存，本相机各段可复用；重新拍照后需要在新图上重新画框。采完恢复生产用的 Line0 门控。
3. **选择合格件。** 在同一示教窗口按 SN 查找历史件，核对项目、配方和帧号后读取原图。已有完整胶边时，画面显示向胶内收缩的取样线；确认后加入合格样本。缺少边线或该帧需要调整时，在合格胶面上画框后加入。分别在胶路两侧稳定底材画框并“加入背景框”。同一组背景框会用于所选各帧，请检查它们在各帧上均落在对应底材。可连续加入多件、多帧，尽量覆盖合格批次间的变化。后端核对录制身份、原图尺寸、设备序列号与实际白平衡。
4. **拟合、试测与复核。** 点击“拟合并保存模型”，在本段设条纹长度（mm）、色斑面积（mm²）和持续偏色长度（mm）的试测门限。拟合失败时可更换样本重试，上一份冻结模型仍可复核。用独立历史件试测，逐帧查看偏黄、偏蓝的轮廓、持续偏色的测站及背景漂移。配方的发布前检查会列出缺模型、缺像素当量和相机模式等问题。对照原图与工艺标注后再确定现场门限。
5. **使用独立模拟器联调。** 通过离线评估生成带 `datasetKind: "synthetic"` 的 `model.json`，在同一窗口点击“导入合成联调模型”。用模拟模型对应的相机编号、模拟序列号、白平衡和背景框，在模拟项目中试测、发布与回放。实拍模型和合成模型会在测量前核对来源。混胶报警保存在 PC 侧，专用 PLC 结果码待协议确认。[合成录制与离线工具](../testing/TESTING.md#混胶色差的离线验证)
