PLC 硬件触发拍照 · 工控机运行 GlueSight
PLC 硬件触发输出↓ 触发线 → 相机触发输入相机 1　相机 2　相机 3曝光时刻由 PLC 硬件信号控制
三台相机↓ GigE 网线相机交换机↓ 图像上传 ／ 参数下发视觉工控机 · GlueSight采集图像、胶路检测、显示与记录
PLC ↔ GlueSight以太网 · Modbus TCP／S7／MC 三选一开始、型号、SN、结束 ↔ 就绪、已布防、检测结果PLC ↔ Robot 控制柜I/O 或现场总线，接口待确认启动、允许、完成、故障
Robot 控制柜 → Robot 本体＋胶枪机器人专用动力／编码器电缆↓ 机械运动、涂胶工件／夹具三台相机光学观察胶嘴附近的胶路

PLC 硬件输出控制拍照时刻；图像通过网线送入工控机，检测结果回传 PLC。

网口相机与交换机按 GigE 方案示意；PLC—Robot 接口、触发电气规格、供电和光源接线按现场确认。
