# 长件浏览与复算

历史详情、示教选帧和试测按原始帧组序号浏览。窗口化、分页和缓存只改变读取与显示方式，不压缩缺帧、屏蔽帧或跳过帧的序号，不改变检测规则。

## 页面读取与显示

- 历史页面用 `history_overview` 读取整件摘要、区域判定、逐帧状态及标量指标；概览保留完整逐帧判定，但不传每帧的逐站胶宽 `widths`。选中帧后通过 `history_frame_detail` 读取该帧完整指标。单帧接口不重新生成整件逐帧判定，格子颜色始终取概览的结论。
- 原图和叠图按相机、帧组查询，单帧读图不再重读整件帧指标。数据库锁内只取原始列，指标解析及判定在锁外进行；图像文件读取、解码和预览生成在后台线程执行。
- 历史、示教、试测帧条只挂载可视列及缓冲列。方向键、Home/End 和外部选帧使用全局帧组序号，跨窗口时保持焦点和选中帧可见。逐帧追溯默认每页 50 行，可切换为 100 行；筛选与外部选帧会重新定位页码。
- 已保存对照先通过 `workspace_comparison_summaries` 读取摘要，选中后用 `workspace_comparison_get` 按 ID 读取完整结果。前端只保留当前选中对照的完整指标；后端摘要缓存最多 1024 项，按文件大小、创建时间和修改时间失效，目标明细读取及删除仍核验文件身份。
- 静态预览沿用二进制像素并直接绘制到 Canvas，不在前端编码 PNG。原图与单帧试测请求共享两个执行槽；切换帧会淘汰尚未执行的旧请求，已执行的原生请求完成后丢弃过期展示。原图缓存最多 24 张且总像素预算为 24 MiB，30 秒失效。

原有 `history_detail` 和完整对照列表接口保留，供需要全量数据的既有调用方使用。

## 分段时间轴按需加载决策

分段工作台以 `plan.pieces` 中示教件的 `groupCount`、已保存边界和笔结构初始化。段落、帧号和编辑操作不依赖缩略图返回；从历史件跳转时直接按全局帧号定位。

- 缩略图接口 `recipe_capture_round_thumbs` 必填 `startSeq`（从 1 起）与 `count`（1–32），只解码指定范围，缩略图最大 160×128 像素；末页返回实际帧数，二进制条带头部的数量表示本页数量。不存在整件读取回退。
- 时间轴按可见范围及两侧缓冲列渲染，保留完整滚动宽度。段色带、相机选择与边界位置使用原始帧号，跳段、键盘选帧和边界编辑不随窗口改变。
- 前端以 32 帧组分页，先请求可见页，再预取相邻一页，不自动遍历整件。缩略图请求最多两个并发，离页或滚动后淘汰过期排队任务；已发出的原生请求允许完成，但不更新旧页面。
- 缩略图使用有界 LRU 缓存，像素预算 32 MiB。加载中、整页请求失败和缺图分别显示，未加载不能当成缺图；单帧文件缺失或解码失败沿用条带的缺图状态。原图预览继续按选中帧读取，使用独立的原图请求调度。

此决策同时限制磁盘解码、IPC 返回量、前端画布数量与跨件缓存。仅做虚拟列表仍会全件解码；仅做分页仍会创建全件节点，因此两端一起修改。不在采集关键路径生成缩略图，不改变录制格式、原始帧序号与分段保存契约。

验证保护的规则：首屏不等待整件图像且读图量有界；范围外原图不被解码；滚动与历史跳转定位保留全局帧号；切换工件不显示旧结果；缓存受预算限制。真实 3000 张原图的首屏耗时、滚动延迟与生产并行负载需现场测量。

## 复算任务与取消

以下命令接受可选的 `taskId`：

- `workspace_compare`：候选规则重判、候选原图复测。
- `workspace_compare_original`：按原发布包重现。
- `workspace_teach_preview_segment`：示教全段试测。
- `workspace_measure_teaching`：测量示教件。

未传 `taskId` 的既有 MCP 调用保持原返回契约。带任务编号的调用通过 `operation://progress` 发出进度：`taskId`、`stage`、`completed`、`total`、`failed`、`skipped`、`elapsedMs`。阶段为准备、测量、汇总、保存以及完成、取消、失败；进度按 150 ms 节流，开始、阶段变化及终态立即发送。计数单位为相机帧，跳过与失败也计入已处理数量。规则重判不执行图像测量，不伪造逐帧测量百分比。

前端先建立事件订阅再调用命令，仅接收当前任务的进度；命令结束后用 `operation_status` 获取精确终态，避免最后一次节流事件未到就显示不完整计数。后端仅保留最近 64 个终态。测量达到总数后，界面仍显示汇总或保存，成功提交后才显示 100%。

`operation_cancel` 在准备或测量等可取消阶段接受请求，在帧间生效；当前帧的 lyFlow 执行不会被强制终止。进入保存阶段后拒绝取消。取消错误以 `OPERATION_CANCELLED:` 标识，不能被逐帧错误处理吞掉后继续返回部分结果。页面退出时撤销尚未提交的任务，已注册任务请求取消；已进入保存的任务完成提交。

历史复算始终另存对照，不覆盖原始检测记录。示教测量先写暂存产物，提交前重新核对候选修订；取消不提交，保存失败恢复原产物。示教全段试测保持只读，运行期间继续检查生产是否空闲。

历史列表批量规则重判 `history_rejudge` 不使用上述任务进度接口。

## 帧数据校验与复用

历史原图复测在实际需要读图时建立读取上下文，按录制目录读取一次 `part.json` 并建立索引；示教测量一次读取并校验 `round.json` 与 `frames.jsonl`，建立帧路径索引。元数据只在本次任务内复用，不跨任务保留可变清单。

每次读取仍核对相机、帧组、帧号、原图路径及尺寸。图像源不存在时沿用逐帧失败处理；全部帧被规则跳过时不打开图像源。原图清理、错误身份、路径越界不能通过缓存绕过。

浏览器结构验证使用合成的 1000 帧组数据，验证窗口、分页和键盘导航。真实图像读取耗时、lyFlow 吞吐及现场生产并行影响需在现场数据上单独测量；软件回归不代表这些指标已验收。验证入口见[测试说明](../testing/TESTING.md)。
