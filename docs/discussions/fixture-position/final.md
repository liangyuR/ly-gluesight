# 定稿：特征定位 + 示教胶路判胶偏

本文只服务旧拍照点配方的遗留代码（`vision/fixture.rs`、`vision/fixture_quality.rs`、`vision/eval/locate.rs`、`workspace/fixture.rs`、`locate_health.rs` 等按节号引用本文，节号与代码注释保持一致）；段配方不使用特征定位，胶偏按直线段段级判定（[分段连拍决策记录](../../decisions/segment-burst.md) D-SB-15）。

## 1. 方案

工件特征定位得到位姿 T，把示教胶中线（合格胶路 N）搬到当帧得到 N'；胶照旧在静态示教线走廊里检测；胶中心到 N' 的有向法向距离即胶偏，按 `limits.position` 判定。

胶检测走廊不随位姿，位置基准随工件。这一拆分不依赖任何关于“胶在画面里跟不跟工件走”的现场结论（MX11 数据不可信，不作依据，见 §8）：

- d = B − T(N) 的定义就是“胶相对工件上合格位置偏了多少”。胶随工件动时，B 与 T(N) 一起动，d 不变；胶不随工件动时，d 如实给出胶相对工件的偏移。两种情形下 d 都正确。
- 走廊保持静态，沿用已验证的胶检测与解析契约（`glue.taught_path` / `glue.bead_width`、`parse_result` 的站数、弧长、法向校验），不引入“走廊随位姿重建”的新失效面。前提是胶落在静态走廊内，走廊宽度见 §5、§9。

## 2. 结构

```text
LyFlow 图（静态，发布包“图一致”校验不变）
  n_load → n_path(taught_path, 静态示教线) → n_width(bead_width) → stations、beadInfo
  n_load → n_locate(glue.locate 1.1.0, template = "template.pgm", templatePad = 4) → pose

GlueSight（Rust 纯函数）
  N' = T(N)
  每个有胶站 i：在 N' 上沿弧长离 N'_i 不超过 r_i = |B_i − N'_i| 的线段上就近投影，两侧各多一段
               （直线段上 B_i 的垂足离 N'_i 不会比 B_i 更远，位姿的平移与绕模板中心转动带来的切向搬移都在窗口内；
                 窗口只挡同一胶路弧长更远的部分，如 U 形的另一条腿）
               取 |距离| 最小、且线段法向与 n'_i 夹角 ≤ 45° 的线段（挡拐角；直角拐点上的站恰为 45°，算合格）
               投影参数不在 [0,1] 内 → 该线段不算；弯道外侧落在相邻两段之间楔形区、两段都合格 → 按共同顶点距离
               越出 N' 两端或窗口两端、找不到合格线段 → ST_NO_REF
  d_i = B_i 到所选线段的有向垂直距离 × mmPerPx，正向取 n'_i 一侧（原始几何距离，名义值在判定里扣）
        即 (B_i − P_i)·m_j，m_j 为线段法向；与 (B_i − P_i)·n'_i 只差两法向夹角的余弦（门限内 ≥ 0.71）
  pose.ok = false → 该视图所有有胶站 ST_NO_REF
```

窗口按每站实际距离开：k = ⌈searchRadiusPx / stationStepPx⌉ 只算了模板中心的平移，漏了方形搜索窗的对角（最多 √2 倍）和绕模板中心转动在杠杆臂 L 上的切向分量（约 L·2·sin(θ/2)，L = 900 px、θ = 3° 时 47 px）。locate 接受的位姿会让整段中间站都找不到线段而报 ERR 92；所以按每站实际的 |B_i − N'_i| 开窗。

## 3. 判定与状态

- 新测点状态 `ST_NO_REF`：有胶、无位置基准，胶宽有效。`PointState::Measured { d: Option<f32>, w }`。
- 位置统计只用有值的 d；`ST_NO_REF` 连续长度按 `MAX_INVALID_LEN`（2 mm）容忍；超过或整视图无基准 → 该段位置 ErrInspect，`SegmentResult.reference_invalid = true`。
- 合并：按现有全序取 max；若 ERR 只由基准无效引起、且存在任一段 NG，则取该 NG。`Verdict` 顺序不动。
- fault 92 由 judge 给出；删除 `Measured.located`、`FrameStatus::LocateFailed` 和 `cycle.rs` 整周期短路；帧增加 `referenceFailed`。
- 定位失败始终可见：帧记录与 UI 徽标；同一（拍照点, 图）连续 N 件没有位置基准（定位失败或两端搬移超限）时告警（见 §14）。
- 名义值：`limits.position.nominal`（默认 0）。验证阶段统计合格样本 d 的 μ/σ 只做诊断，不自动校正；`nominal ≠ 0` 时必须填写量具确认件编号 `gaugeRef`。改名义按相同测量定义重判历史；改 fixture 需原图重测。

## 5. GlueSight

- **配方**：`fixture: Option<FixtureSpec>`（`rect`、`searchRadiusPx`、`angleRangeDeg`、`minScore`、`maxPeakRatio`）进入 `ShotSpec` / `ShotViewSpec` / `for_view` 及其全部同步点；`gaugeRef` 进 `ShotLimits`。`RECIPE_SCHEMA` 7；`measurement_layout` 纳入 fixture。
- **模板**：保存 fixture 时由冻结示教原图裁出带 4 px 外圈的 `template.pgm`（`rect` 四周各多 4 px，文件 (w + 8) × (h + 8)），`templatePad = 4`，`anchor` 仍是 `rect` 左上角；`rect` 离图边不足 4 px 时示教保存拒绝（locate 会报 `out_of_image`）。外圈让模板与搜索区一样按真实邻域预平滑，去掉框边强边缘带来的平移偏置（lyFlow#32）；发布包放 `shots/kk/vN/`，加载时按配方重算比对；复测/重现只用包内模板。工作台在使用时按冻结原图裁出、按来源寻址，见 §11。
- **base_dir**：图内固定写 `template.pgm`；工作台指向 workspace 图目录，生产指向发布包 shot 目录，评测/离线工具指向样本目录；有 fixture 且 base_dir 为空时 `plan` 报错。
- **走廊**：`search_mm` 逐点按阶段 0 的 σ_B 取 `max(3σ_B, 胶宽上限/2 + 2 px)`；σ_B 超阈值的点关闭位置判定。
- **示教**：框选定位特征（叠加模板框、搜索范围、杠杆臂 L）；保存检查模板与走廊不重叠、纹理、`peakRatio`、L；优先与胶同面、刚性、不被喷嘴遮挡的孔或角点；在样本库其他图上做定位试测；试测标签与草稿比较纳入 fixture。
- **验证**：独立合格样本全部定位成功；位姿超出搜索范围 70% 告警；d 的 σ ≤ 位置公差 1/5；|μ − nominal| > 公差 1/3 告警。
- **存储/叠图**：位姿写入 `FrameView` JSON（各视图结果 `viewResults[].pose`）；`POINTS_FORMAT` 3；audit `d_bits` 可空；示教、生产、历史叠图按位姿画 N' 与模板框。
- **版本与依赖**：`RELEASE_SCHEMA` 3、`GRAPH_VERSION` 新值；`requiredOperators` 加 `glue.locate`，以 `runtime.json` 为唯一来源（§8 第 3 项，Rust 编译期读取，不再需要一致性测试，见 §11）；打包自检加 locate 冒烟。

## 9. 数据与局限

阶段 0 只有 2026-10-17 样本集（1 件、单圈、未标定）。它能测的：

| 能测 | 方法 |
| --- | --- |
| 模板候选能否找到：纹理、与走廊不重叠、杠杆臂 L、自匹配分数 | 每张图按规则自动提议候选框，在同图上跑 `glue.locate` |
| 定位精度 | 整图刚体扰动（平移、旋转、缩放）单独及叠加成像扰动（噪声、亮度、模糊），真值由扰动定义给出 |
| 共同运动下 d 不变 | 同一刚体扰动下静态走廊测胶，再用位姿算 d，对比原图 |
| 只移胶的检出 | 评测已有的合成偏移缺陷（1/3/6 mm）：模板区不动，位姿应为恒等 |
| 定位耗时 | 单线程逐张计时 |
| 复拍对比（3 对） | S001/S034、S002/S035、S003/S036：用原图模板定位复拍图，比较静态 d 与定位后 d 的差 |

它测不了的：

| 测不了 | 原因与后续 |
| --- | --- |
| 件间胶位抖动 σ_B | 只有 1 件；3 对复拍不构成分布。§5 逐点 `search_mm` 不按 σ_B 设定，沿用默认值 |
| 已知物理偏移的线性度 | 没有 0.5/1/2 mm 实物偏移样本，只能用合成偏移代替 |
| 视差与高度：特征与胶不同面、工件倾斜 | 合成扰动都是整图平面变换，测不到 Z 向变化 |
| 真实 mm 刻度 | 未标定，mm 值来自模拟当量 |
| 模板框里是否有喷嘴或胶枪 | 随枪相机下喷嘴跟相机走，框进去会让位姿恒为恒等；工具判断不了，每个选中的框都要人工复核 |

后续采集至少需要：多件、同一件重复上下件 ≥ 10 次、已知偏移样本（0.5/1/2 mm）、标定后的当量。

阶段 0 评测（`vision/eval/locate.rs`）中影响实现的三条：

- **locate 假角度**：glue.locate 1.0.0 在有噪声的图上估出 0.3–0.7° 的假角度（φ = 0 不经插值、其他角度经双线性插值），三对复拍图的 d' 因此比静态 d 还抖；只找平移时 d' 重复性优于静态。locate 1.1.0 让各角度走同一插值路径（见 §10）。整图过曝时有错锁仍报成功；§10 表明 `peakRatio` 与 `minScore` 都分不开这些错锁、`at_angle_edge` 只拦下一部分，所以 `maxPeakRatio` 默认保持 1，改由验证时的亮度 ±40 试定位把关。
- **胶路两端**：共同运动带切向分量时，胶路两端约一个切向位移长度的站投影越出 N'（无基准），按 §3 的 2 mm 容忍会报 ERR（平移 2.9 mm 时 21/36 张）。§10 决定一：新增“超出检测范围”状态加护栏，示教余量 m 默认 0、由验证建议写入。
- **选框**：自动提议的框会落在离焦前景件、镜面高光或喷嘴边上。亮像素比例只作示教保存时的预筛，必须过的检查是验证时每个框在亮度 ±40 下的离线试定位（§10）；另要求人工确认不含喷嘴。

## 10. 阶段 0 结论

依据是阶段 0 评测在 locate 1.0.0 与 1.1.0 上的结果，数据都来自 2026-10-17 样本集。证据范围：只有 1 件；除复拍外都是同图内的合成扰动；跨图证据只有 3 对同点位复拍，真实转角未知。MX11 数据没有用。

**已验证（同图内）**

- **几何链路成立。** 原图上 d' − d 的 P95 为 0.003 mm（1.0.0；1.1.0 因角度噪声为 0.017–0.023 mm）。工件共同平移 5–25 px 时 |Δd'| P95 ≤ 0.083 mm，静态 |Δd| 是 0.57–2.91 mm；+40 px 时两端的站占了上风（|Δd'| P95 6.8 mm，静态 4.66 mm，见决定一），中间段的 d' 仍是对的。合成只移胶 1 / 3 / 6 mm 全部按预期判定，位姿不漂。
- **locate 1.1.0 去掉了插值与亚像素相位造成的假角度。** 同一组框上只加噪声 σ=6 时角度误差 P95 从 0.75° 降到 0.046°；代价是整像素平移时多了约 0.03° 的角度噪声（1.0.0 在 0° 上不经插值，恰好偏向真值 0）。
- **复拍对分开看。** 同一组框（1.0.0 选的）上，S001/S034 从 0.53° / |Δd'| P95 0.204 mm 降到 −0.03° / 0.029 mm（静态 0.051 mm），这是相位修复的效果；S002/S035 仍报 0.11°、0.105 mm，与静态 0.102 mm 相当、比只找平移的 0.043 mm 差；S003/S036 判看不出角度、只补平移，0.050 mm。1.1.0 自动选的框上三对是 0.029 / 0.079 / 0.055 mm，都低于静态 0.051 / 0.102 / 0.061 mm，但 S002/S035 在自动选框上也报 0.13°、仍比只找平移（0.053 mm）差。S002/S035 的真实转角未知，只有这一对，算 n = 1 的证据。
- **贴边门有效。** 平移 +70 px（超出 searchRadius）36/36 判 `at_search_edge`，1.0.0 下则全部报成功、全部错锁。旋转 +4° 时两组框都是 36/36 判 `at_angle_edge`，看不出角度的分支也不再绕过它。
- **耗时够用。** 按评测 E5（单线程，每张图 5 次，含建图、调用、解析；96 / 128 px 模板、searchRadius 60 px、±3°）P50 约 21 ms、P95 ≤ 28 ms，不需要金字塔；只找平移时更快。LyFlow 记录里的内核单独计时没记构建配置、与 E5 对不上，不作依据。

**没通过、要改的**

- **错锁门拦不住大部分过曝错锁。** 亮度 +40 下有 10/36 次错锁，分数 ≥ 0.98，`peakRatio` 不高于锁对；`at_angle_edge` 拦下其中 1–4 次，`minScore` 从 0.6 扫到 0.9、`maxPeakRatio` 从 1.0 扫到 0.7 都多拦不下一次，反而先误拒锁对。错锁还会造成假 NG：S017 错锁 38.4 px，被判位置 NG。示教时的亮像素比例筛框只能减少、不能杜绝：自动选框时取比例 < 0.1 的框，亮度 ±40 下 0 次错锁、4/36 个拍照点选不出框；但固定 1.0.0 选的框时，S016 比例 0.099 仍错锁 19.8 px（1.0.0、1.1.0 下都是）。0.1 这个门限是在同一批 36 张、单一扰动上挑出来的。所以亮像素比例只作预筛，**每个框在验证时用亮度 ±40 离线试定位才是必须过的检查**。`maxPeakRatio` 默认保持 1。叠加了亮度 +40 的组合用例里，另有 9–19 次看不出角度、中心偏 2–10 px 的定位按“转角没补偿”计、没算进错锁（亮度 +40 单独就会在这个分支上错锁），实际的错锁可能更多。
- **转角补偿逐帧不稳，没补偿时平移也偏。** `angleObservable` 在 21–30/36 个拍照点上时有时无。看不出角度时只补平移：合成 ±1–2° 转动下，范围内、不含亮度 +40 的定位里有 50–70 次转角没补偿，其中 24–46 次模板中心偏 2–8 px；1.0.0 在这些用例上只有 1 次错锁（缩放）和 179 次角度超差。开了转角的拍照点因此必须把 `angleObservable = false` 当定位失败。
- **缩放（工作距离变化）补不了。** 这条不变。
- **胶路两端。** 见下面的决定一。

**决定一：胶路两端在切向搬移下的处理（§8 第 7 项）**

两端被位姿搬出 N' 的站按下面第 1、2 条（新状态“超出检测范围” + 按 |Δ| 判的护栏）处理，第 3 条示教余量 m 默认 0、由验证建议写入。代价：每帧两端约 |Δ| 长的站不判胶偏、不判断胶；m > 0 时两端各 m 长永远不判。

现象：位姿把胶路沿自身切向搬 Δ 时，前沿一端的胶落在 N' 端点之外，这些站没有基准；后沿一端的静态走廊里已经没有工件上的胶。按 §3，前者连续超过 2 mm 判 ERR 92，后者判断胶。d' 本身是对的：平移 +25 px（约 2.9 mm）时 |Δd'| P95 为 0.083 mm，但 36 张里有 22 张判 NG（21 张 ERR、1 张断胶）；平移 +40 px 时 25 张判 NG。正常件因此停线，原因只在两端。

做法：

1. **新增站状态“超出检测范围”，与 `ST_NO_REF` 分开。** 每个视图按位姿算两端的切向搬移：Δ_起 = (T(N_0) − N_0)·t_0，Δ_止 = (T(N_n) − N_n)·t_n，t 是端点处沿胶路方向的单位切向。离检测区起点（或终点）弧长不超过 max(0, |Δ| − m) 加 1 个站距的站（单端排除长度），记为超出检测范围；m 是下面第 3 条的示教余量。这些站不参与位置判定和断胶判定，也不计入 `ST_NO_REF` 的 2 mm 连续长度。帧里记下两端各排除了多长，叠图上标出。理由：这些站是几何上本来就测不了，不是检测失败。判 ERR 会让正常件停线，判断胶是误判。
2. **护栏。** 护栏按切向搬移本身判，不按排除长度判：任一端 |Δ| 超过配方上限 `maxEndShiftMm` 时，该段位置判 ERR 92（`reference_invalid`）。这样位姿搬得太远时，覆盖损失不会悄悄变大；按 |Δ| 判也与 m 无关（若按排除长度 max(0, |Δ| − m) + 1 站距判、门限又按 m = 0 的数据定，取 m ≈ P99 之后要 |Δ| 到约 2·P99 + 1 mm 才触发，比设想宽一倍）。上限要高于正常运行时最大的切向搬移并留余量，否则护栏在正常件上就会触发：评测按 m = 0 算的单端排除长度（= |Δ| + 1 个站距，本样本集站距约 1 mm），平移 +25 px 时 P50 3.66、最大 3.92 mm，+40 px 时最大 5.67 mm。建议值：验证时两端 |Δ| 的 P99 再加 1 mm（§13）。配方没给时的默认取 locate 接受的位姿能产生的最大 |Δ|：搜索窗是方的（每个轴 ±searchRadius，峰离窗边 ≤ 1 px 判贴边），平移最多 √2·(searchRadius − 2) px；开转角时端点还绕模板中心切向移 L_端·2·sin(angleRange/2)（L_端 是模板中心到较远端点的距离）。即 `maxEndShiftMm` = √2·(searchRadius − 2)·mm/px + L_端·2·sin(angleRange/2)：本样本集 60 px、约 0.117 mm/px、只找平移时约 9.6 mm，±3°、L_端 87 mm 时再加约 4.6 mm。按构造，定位成功的位姿不会因两端判 ERR；代价是用默认值时每端最多可排除约 |Δ| + 1 站距 ≈ 10.6 mm（只找平移）而不报 ERR。评测里没有接近搜索半径的对角平移，这个上界没有实测。
3. **示教余量。** `glue.taught_path` 的 `zone` 取 [m, L − m]，静态走廊和判定只覆盖 zone 以内；偏差投影要用整条示教线 N，不能只用 zone 内的站。这样 |Δ| ≤ m 时 zone 内的站都能投到 N' 上，静态走廊里也仍然有胶，不排除任何站。m 默认 0；验证时按两端切向搬移的 P99 加 1 个站距来取。代价是两端各长 m 的一段（起胶、收胶）永远不判。第 2 条的护栏按 |Δ| 判，取 m 之后门限不用跟着改。
4. 胶检测走廊仍然是静态的（§1），不引入“走廊随位姿重建”。

**决定二：v1 默认只找平移（`angleRange = 0`）（§8 第 8 项）**

v1 默认 `angleRange = 0`，开转角逐拍照点由验证决定（条件见下）。代价：真有转动时只补平移，合成 1° / 2° 下最远站误差 P95 约 1.3 / 2.7 mm。

证据：

- **不转动时，只找平移不比 ±3° 差，S002/S035 上两组框都更好。** 噪声 σ=6 下最远站误差 P95 为 0.023 mm（±3° 为 0.054 mm）。复拍 |Δd'| P95：自动选框 0.028 / 0.053 / 0.055 mm，±3° 为 0.029 / 0.079 / 0.055 mm；1.0.0 选的框上 0.029 / 0.043 / 0.050 mm，±3° 为 0.029 / 0.105 / 0.050 mm。
- **±3° 的补偿取决于“看不看得出角度”，逐帧不稳；看不出时平移也偏。**
- **代价：** 真有转动时，只找平移在 1° 下最远站误差 P95 为 1.3 mm，2° 下为 2.7 mm（合成，杠杆臂 35–87 mm）。纯转动时 |Δd'| 只比静态好约 12%（±1°：0.93 vs 1.06 mm）；带平移的转动好得多（平移 +20,−10 加 1.5°：1.38 vs 3.52 mm），因为平移被补掉了。样本集里没有真实转动的数据。

做法：

- v1 默认 `angleRange = 0`。
- 是否对某个拍照点开转角，由验证（多件实拍）决定，三个条件都要满足：
  - 用 ±3° 离线跑验证帧，L·|θ| 的 P95 超过位置公差的 1/5（公差 ±2 mm 时为 0.4 mm，L = 87 mm 时对应 0.26°）；
  - 这个转角要有独立于单个模板的证据，因为同一个估计器在同点位复拍上报过多半与真值无关的角度（S002/S035 在两组框上报 0.11–0.13°、真值未知，71503de 之前 S001/S034 报 0.48°），量级接近 0.26°。满足其一即可：同一视图两个不同的模板估出的 θ 一致；验证帧上 ±3° 的 |Δd'| 明显低于只找平移；多件采集时实物确认转过；
  - 选中的框在全部验证帧上（含亮度扰动）都是 `angleObservable = true`。
- 开了转角的拍照点，运行时遇到 `angleObservable = false`，按定位失败处理：该视图 `ST_NO_REF`，判 ERR 92，计入连续 3 次告警；不要悄悄降级成只补平移。
- 只找平移的拍照点没有角度门保护，所以验证阶段同样要用 ±3° 离线核对真实转角；超过上面的门限，就开转角或改夹具。

**其他**

- 模板带 4 px 外圈（lyFlow#32，见 §5“模板”）去掉了框边 BORDER_REPLICATE 平滑偏置：两组框上纯平移的模板中心误差 P95 约减半（0.115 → 0.059、0.086 → 0.042 px），纯平移的最远站误差 P95 减 0.020–0.026 mm（模糊、亮度 −40 与带转动的用例减得更多），亮度 +40 的错锁不变；两项转角问题是已知问题（v1 只找平移）。
- 示教保存检查用亮像素比例上限作预筛（0.1），必须过的是验证时的亮度 ±40 试定位。
- σ_B、实物偏移线性度、视差、真实转动没有数据（§9）。

## 11. 工作台模板与跨阶段约束

- **模板生命周期。** 工作台不在保存 fixture 时裁模板，而是每次试测、验证、候选试运行时按该视图当前的冻结示教原图重新裁，写到 `<workspaces>/<配方>/fixtures/<冻结图>-r<x>_<y>_<w>_<h>-p4/template.pgm`（按来源寻址，内容不同才原子重写），base_dir 指向这个绝对目录。旧目录的清理见 §13。
- **requiredOperators。** 按 §8 第 3 项由编译期读 `packaging/runtime.json`，测量图里的每个算子都要在这份清单里（`vision::tests`）。
- **跨阶段约束。** 模板框盖住胶时位姿跟着胶走，d′ 恒约等于 0，真实胶偏会被放行。由配方校验里的走廊检查（含同 Pose、同相机、同一幅图的其他拍照点，见 §12）挡住，剩余风险靠 §13 的人工确认。

## 12. 发布、加载与生产接线

- **模板身份 = 来源身份，不用内容哈希。** `FixtureSpec.source` 记裁模板用的冻结示教原图编号，身份三元组是 (source, rect, `FIXTURE_TEMPLATE_PAD_PX`)，它在测量布局里（fixture 含 source；布局顶层另有 `"fixtureTemplate": {"pad": 4}`）。成立的前提，都写在代码注释里：
  - 冻结图按编号只写一次：`image_file::save_pgm_new` 用 create_new，文件已在时逐字节比对，相同照常（同一圈重复采用）、不同报错。逐字节比对不是哈希；
  - 发布包复制的是同一份字节；工作台与发布包都用 `template_pgm(image_file::decode(字节), rect)` 裁模板；
  - 改 `template_pgm` 的裁法必须同时改布局里的 `fixtureTemplate`。
  跨配方：布局比较不含配方编号，但历史重判的候选按记录的配方编号取，冻结图编号在工作区内唯一；两个配方采用同一圈时编号相同，像素也来自同一份圈原图。
- **来源由后端掌管（`bind_fixture_sources`）。** 前端传来的 source 一律不用。只有“保存示教参数”强制把所选视图的框改绑到当前冻结图；草稿自动保存与整份保存（`workspace_save_doc`）只给新增或改动的框绑定当前冻结图，没动的沿用旧来源——否则重新冻结后任何一次自动保存都会把旧框悄悄绑到新图上。冻结、整圈采集（含继承示教）、恢复示教都不改写来源（恢复示教只回滚帧，不回滚配方）。使用时 `fixture_source` 要求来源就是该视图当前冻结图：试测、验证、候选试运行、发布前都经过它，过期的框报“定位框是在示教图 X 上保存的，当前示教图是 Y”，要在示教页确认框后重新保存示教参数。
- **走廊检查（§11 跨阶段约束）。** `RecipeDoc::validate` 里，按 (Pose, 相机, 图) 分组：同一 Pose、同一相机、同一幅图的几个拍照点拍的是同一场景的不同帧（同一 Pose 可多次触发），组内每个启用的框（带外圈，按像素中心 [x − 4, x + w + 3] × [y − 4, y + h + 3]）到组内每条已示教中线及其两端切向延长线的精确距离（线段、射线到矩形）必须大于该线搜索半宽 + 4 px。两端各沿末段方向延到无穷远（对图内的框即延到图边，与图像尺寸无关）：枪上相机里同一条胶通常越过示教段两端继续留在画面里（各拍照点只测自己的检测区），只量示教段时端点处是半圆帽，框放在胶的直线延长上也能发布，模板里却有胶。代价是胶确实在示教段端点结束时，延长线上的框也被拒，要换位置。余量 4 px 的来由：阶段 0 选框时要求内框离走廊大于 10 px，外圈在角上最多近 4√2 px，阶段 0 选出的框到这里还剩约 10 − 4√2 ≈ 4.3 px（不计每 2 px 取点的采样误差）；阶段 0 选框时的走廊不含切向延长，落在延长线上的这类框在这里会被拒。停用视图、不检拍照点的框与中线不参与。带外圈的框在图内（右、下边要看图像尺寸）由工作台保存示教、发布与加载时用 `check_image_size` 查。校验也作用于草稿自动保存与配方页改 `search_mm`，压走廊的框会让这些保存失败。剩余风险：几何检查只认同组示教中线及其直线延长，胶越过示教段两端后拐弯的部分、不同 Pose 或其他胶路的胶进到模板里拦不住（见 §13“人工确认”）。
- **发布包（`RELEASE_SCHEMA` 3）。** 启用 fixture 的视图在 `shots/kk/vN/` 下带 `template.pgm`（(w + 8) × (h + 8) 的 P5），清单每个视图记 `imageId`（有图则必有）与 `template`；发布时要求来源 = 发布原图编号、带外圈的框在图内；加载时按包内原图与配方重算模板比对（与中线、测点同一机制），fixture 视图必须引用模板、非 fixture 视图不得带模板，声明集合与引用集合一致。已知局限（与原图、中线相同）：按部件 `verify` 只核对大小，同尺寸替换要到下次 `load_directory` 才发现。
- **运行库能力。** `vision::require_locate(recipe, &engine.locate)`：运行库不支持带外圈模板时只挡含特征定位的配方，发布前（`freeze_bundle`）、生产加载与重现（`Prepared::load`）、候选试运行调用。
- **生产 base_dir。** `Prepared` 只给启用 fixture 的视图登记 base_dir = 发布包里该视图的目录（UTF-8 绝对路径），其他视图照旧给空串，与工作台、候选试运行一致；`measure`、`measure_views`、`warm` 与重现都经 `measure_view`。
- **预热的定位验收。** `warm()` 在发布包自己的示教原图上跑每个视图，fixture 视图位姿必须被采用，否则不布防并报出 locate 原因。这是生产接线验收，不是 §13 的质量门。
- **位姿存储。** `ViewResult.pose`（帧记录的各视图结果）保存 `PoseRecord`（含没被采用的）；`Measured.poses` 在单图与多图两条路径都填。叠图时 T 由 `offset`、`angle` 与快照里 `rect` 的示教中心还原（§14）。
- **打包自检。** 应用自检的 `lyflow.locate` 只报告状态：运行库不支持带外圈模板 → `unsupported`（写明影响，不算失败）；支持 → 跑合成图冒烟（示教图位姿被采用且偏移 ≈ 0，整图平移 (+6, +4) 后偏移 ≈ (6, 4)、胶偏不变），失败即自检失败。放不放行由 `packaging/runtime.json` 的 `lyflow.locateSmoke` 决定（`optional` 警告、`required` 失败，只给打包脚本读），现为 `required`，见 [lyFlow 运行库依赖](../../architecture/lyflow-dependency.md)。

## 13. 示教检查、验证统计与两端参数

下面标 D1–D5 的是实现时选定的做法，其中 D1、D3 与 §10 字面不同。

- **页面职责。** 示教页“定位特征”只管一幅冻结示教图上的事：画框与微调、实时几何与纹理检查、示教图上的定位验收（决定试测是否有效）、样本库其他帧上的定位试测（只作诊断，不落盘）、喷嘴人工确认、来源过期提示、开转角的高级确认；示教余量 m 与两端搬移上限只读。需要独立正常样本的统计（σ、μ、±40、两端 |Δ|、±3° 转角证据）全在验证页。规则页只加位置名义值不为 0 时的 `gaugeRef`。生产页与历史页的叠图见 §14。
- **示教图检查（保存门）。** `vision::fixture_quality`：外圈在图内（`padded_rect`）；走廊复用 §12 的几何（`RecipeDoc::fixture_clearances`，配方校验与检查共用）；纹理 σ ≥ 12、亮像素（≥ 215）比例 < 0.1，口径与阶段 0 评测选框相同（`eval/locate.rs`）；杠杆臂 L 只告警，门限是“0.25° 未补偿转动在最远站的误差超过公差/5”（公差 ±2 mm 时 L ≈ 92 mm）；示教图自定位必须被采用（含 minScore、maxPeakRatio 门，开转角时还要看得出角度）且偏移 ≤ 0.5 px、开转角时角度 ≤ 半个扫描步长。`peakRatio` 检查实际就是 locate 自己的 maxPeakRatio 门（默认 1，不判）：§10 已表明 peakRatio 分不开过曝错锁，真正的把关是验证时的亮度 ±40。
- **试测有效 = 胶路判定可用且示教图检查通过**（定位验收）。报告存进 `Trial.fixture`；`Teaching::checked` 对特征定位视图要求报告存在且通过，没有报告的试测在保存示教、验证、发布、历史复测（都经 `checked_view`）上一律失效，进度页显示“试测早于特征定位检查”。画框时先调只读的 `workspace_fixture_check`，外圈或走廊没过的框不进草稿，免得草稿自动保存撞上配方校验。
- **人工确认（D5）。** 保存示教的 `fixtureReviewed` 必须为 true，不落盘；重新试测后前端要重新勾选。确认的内容是框内没有胶（含越过示教段后拐弯、其他 Pose 或其他胶路的胶），也没有喷嘴、胶枪等随相机不动的结构。**§12 留下的“胶进到模板里”剩余风险只靠这条人工确认，没有自动门**：亮度 ±40 只能抓住亮度变化下被采用的错锁，看不见框里的胶（正常样本上胶在原处，位姿跟着胶走，d′ ≈ 0）；`peakRatio` 检查就是 locate 自己的 maxPeakRatio 门（默认 1，不判）。不要假定有自动拦截。
- **定位试测（D4）。** `workspace_fixture_trial` 只用已保存的框与模板（`fixture_bases`），在示教图（对照）与样本库里同一拍照点、同一幅图的原图上跑 `measure_shot`，锁内取快照、锁外计算、结束时核对修订号，不落盘；示教图上定位没被采用时整次试测无效。离线样本集回放的样本与示教图是同一批图，这个诊断在离线模式下没有信息量；用样本库的图调框也会让验证样本轻度变成调框依据。
- **验证统计**（`fixture_quality::validation_report`，现无调用方，发布前不再查特征定位统计）。设计是只有发布验证的独立正常样本跑探测（`measure_images_from` 的 `probes`，比较与复测不跑）：同一张样本图、同一个模板目录上，按配方门限跑整图亮度 ±40，再用 `angleRange = max(配置, 3°)` 的投影配方跑原图与 ±40。每件每个特征定位视图多 5 次运行。
  - σ、μ（D2）：每个视图取全部独立正常样本、全部有基准站（ST_OK）的 d′ 合并算（单件也能算）。逐站跨样本的 σ 要至少 2 件，当前样本集做不到。
  - 阻断：任一正常样本定位失败；σ > 公差/5；±40 错锁（被采用但离原图位姿 > 2 px 或 > 0.3°，评测的锁定判据）；±40 有一次没跑出结果（测量报错或没有位姿，带原因列出），或全部 ±40 都没被采用（一次锁对都没有，证明不了锁得对）；开了转角的视图在任一帧（含 ±40）看不出角度。告警：位姿单轴超过 0.7 × 搜索半径；|μ − 名义| > 公差/3（不校正）；部分 ±40 被拒（至少有一次锁对时）；只找平移且 ±3° 下 L·|θ| 的 P95 > 公差/5（D3：只告警，见下）；两端参数没采用建议或与本次建议不同（`endParams`，见下）；样本少于 10 件。公差统一取生效位置限值的 min(上公差, 下公差)。
  - 结果进 `Validation.fixture`（每视图一份报告）和发布前检查“特征定位”。
- **两端参数建议与示教余量 m（D1，决定一第 3 条）。** 建议 = 两端 |Δ| 合并的最近秩 P99：`maxEndShiftMm = P99 + 1 mm`、`m = P99 + 1 个站距`，都向上取到 0.1 mm；m 会让胶路剩不下 3 站可判时不给“采用”。“采用建议”（`workspace_apply_fixture_suggestion`）只从同修订的验证统计取数，前端不传数值；写入后该视图试测作废、修订号前进、整套重验。这也是唯一的写入口：草稿自动保存、整份保存与保存示教参数只能原样带过两端参数（改框时也带过）或回到默认（不设上限、m = 0），其他改动一律拒绝（`reject_end_param_edit`），否则载荷可以把 m 设大、上限放宽，两端永远不判、护栏失效，验证与发布照样通过。没采用建议（上限仍是 §10 的默认公式，本样本集只找平移时约 9.6 mm）或与本次建议不同时，验证只告警（`endParams`）、不阻断发布。建议只依赖 |Δ|，与 m 无关，采用后重验不会循环。m 在 GlueSight 侧实现（`FixtureSpec.endMarginMm`）：图里 zone 仍是 [0, 0]，离 N 首末不到 m 的站不管定位成败都记“超出检测范围”并清掉胶宽与胶边，位姿搬移从 N 端量起排除 max(m, |Δ|) + 1 个站距（= 从 zone 起点量的 max(0, |Δ| − m) + 1 个站距），偏差投影仍用整条 N。判定与 zone = [m, L − m] 等价（只差余量边界落在站距之间时那一站），代价是站表、`parse_result` 的弧长核对、`deviations` 签名与 `GRAPH_VERSION` 都不用动；按字面改 zone 要动这些。`plan` 要求两端各排除 m 与 1 个站距后至少剩 3 站（原来是 5 站总数，即剩 1 站）。
- **转角（D3，决定二）。** v1 默认只找平移，UI 不提供转角开关。验证页给出证据：±3° 下原始验证帧 L·|θ| 的 P95 与公差/5 对比、全部帧（含 ±40）是否都看得出角度；第三个条件（独立证据）只能人工确认。开转角只能在示教页高级设置里选一种独立证据（两模板一致 / 开转角 |Δd′| 明显更低 / 实物确认）并写说明，经“保存示教参数”带 `rotation` 调大，确认记进应用日志；后端另要求与候选同修订的验证里该视图的转角证据满足前两个条件（`rotation.autoConditions`），没有当前验证或不满足时拒绝，界面上的确认按钮同样不可用（决定二“三个条件都要满足”）；草稿自动保存、整份保存调大转角一律拒绝（`reject_unconfirmed_rotation`），调小不拦。只找平移的视图测到转角超门限时只告警、不阻断：单模板的假角度在 0.11–0.13°，公差收紧到 ±0.5 mm 时门限低到约 0.07°，硬拦会让人既发布不了、也拿不出开转角的独立证据。决定二字面是“开转角或改夹具”，相当于硬拦。
- **`gaugeRef`。** 示教页（本图自定义位置限值）与规则页（配方默认）在位置名义值不为 0 时出现“量具确认件编号”，示教页为空时不能试测；后端另有校验。
- **模板目录清理。** `prune_fixture_dirs` 在保存候选与启动加载时删掉 `fixtures/` 下不再对应候选（含待生效版本）任何定位框的目录，以及放了 10 分钟以上的临时文件；删不掉（被 lyFlow 打开）就留到下次。模板按需重裁，误删只多裁一次。
- **失效规则**补充：采用建议与改框同属测量定义，作废该视图试测与整套验证；只改名义值或 `gaugeRef` 时试测仍失效（限值在试测标签里），历史可重判（§12）。

## 14. 叠图与连续定位失败告警

- **叠图的唯一变换。** `src/features/cycle/pose.ts`：T(p) = R(angle)·(p − tc) + tc + offset，tc = 示教框中心 (x + (w − 1)/2, y + (h − 1)/2)，offset = `PoseRecord.offset`（center − teachCenter），旋转矩阵与 `vision/fixture.rs` 的 `Pose::rotate` 逐字对齐（y 向下，angle > 0 为屏幕顺时针）。示教页 `fixtureOverlay` 的杠杆臂中心也改用同一个 `teachCenter`。
- **只看 `accepted`。** 未采用的位姿 offset 仍可能是有限数（at_search_edge 错锁 38 px），叠图（`poseTransform`）一律不搬：中线与站点留在示教位置，框用故障色虚线、标“定位未采用：原因”。“两端搬移超限”的位姿是被采用的，照常搬，站点按无基准样式显示，原因看帧徽标。没有位姿（未测、测量出错）时不画定位框，只画示教中线。原因码的中文与 `fixture_quality::reason_text` 同一张表（只用于显示，不写测试）。
- **站点画 T(N_i)，不画实测胶中心 B_i。** 历史测量点 BLOB 只有 d、w、st，没有像素位置；画 B_i 要 `POINTS_FORMAT` 4 与 `DB_VERSION` 9 重建，不是最小改动。非 fixture 帧本来也画名义位置。叠图需要的 rect、offset、angle 都已在快照与 `viewResults[].pose` 里，**历史不改存储**，不升 `DB_VERSION`、`POINTS_FORMAT`。
- **半像素约定。** 中线与站点是像素中心坐标（lyFlow 口径），原来定位框用 `<rect>` 画在 [x, x + w]，比中线差半像素。所有定位框（含示教页的示教框、外圈、搜索范围）都用 `movedBox` 的四角多边形，角点取 [x − 0.5, x + w − 0.5]，示教页与生产、历史页一致；开转角时示教位置的框也是多边形。
- **快照配对。** 位姿只和测出它的配方快照配对：生产页的选中帧、缩略图（`ShotTiles`、`ShotStrip`）都经 `partFrames`，件的配方或修订与布局不同时不按位姿画（与 `computeVis` 同口径）；历史页的快照按修订读取，天然匹配。
- **多视图投影。** 有 `views[]` 时 path 与 fixture 取 `views[view]`（照 `ShotSpec::for_view`），shot 级 fixture 可以为空；站点按 `segments` 里 (shot, view) 取（照 `view_points`）。叠图只画检测所选视角（`shot.view`），历史页仍只在所选视角上叠图。已知的存量问题：非 fixture 的叠图仍用 `shot.path` 与第一段 `shotSegment`，不分视图。
- **缩略图。** `ShotLine` 的彩色站画在 T(N_i)，宽描边留在 N 作示教位置底色；有 fixture 时画幅四周多留 √2·(searchRadiusPx − 2)，件间画幅不跳、平移后不被裁掉。开转角时杠杆臂的切向分量不计入（v1 只找平移），转角大时远端可能被裁，记为已知局限。
- **生产页与历史页的摘要。** 选中帧状态栏加“定位”：采用 · 偏移 (dx, dy) px · θ° · 两端排除 a / b mm，或“未采用：原因”；检测页的紧凑状态栏只显示“采用 (dx, dy) px”或“未采用”，全文放在悬停提示里；历史页原图下方是全文一行。
- **复测对照。** 按原发布包重现、从原图复测（不含规则重判）后，若该视图复测的位姿与原记录采用与否不同、转角差 > 0.05°，或原示教框中心经两次变换后的落点相差 > 0.5 px（`REPLAY_POSE_PX`、`REPLAY_POSE_DEG`，同一原图同一模板应逐位一致，只吸收序列化舍入），原图上另画橙色虚线“复测定位框”（框取 `comparison.candidateRecipe` 的 fixture）并列出两次的偏移；中线与站点仍按原记录位姿画，与“站点颜色表示原始判定”一致。比较在图像上做：offset 是相对各自示教框中心的，从原图复测用的是工作台当前候选，框可能改过，开转角时同一个变换在两个框下的 offset 差 (R − I)(tc′ − tc)，直接相减会把同一个锁定误报成不同、也会漏掉 offset 数值碰巧相同的不同锁定；转角是变换的线性部分，与转心无关，直接比。
- **示教页只在自定位没通过时画落点。** 保存门已保证偏移 ≤ 0.5 px，通过时叠出来与原框重合，还会盖住正在编辑的框，所以不画；`selfLocate` 没通过时：未采用画候选落点（故障色虚线），已采用但偏移超出容差画移动后的框。可编辑的中线不替换成 N′。定位试测行逐行看图（显示样本帧上移动后的框）没有做。工件总览页不改（没有测量，示教图上是恒等位姿）。
- **连续定位失败告警（`locate_health.rs`）。**
  - 键：(分槽, 配方, 拍照点, 图)；条目记修订、k、连续件数、首次失败时间、最近一件的 cycle 与原因。门限 `LOCATE_ALARM_PARTS = 3`（§8 第 5 项），到 3 时报出现，此后只更新内容、不重复报。
  - 证据只认帧记录 `FrameView`（与帧徽标同一来源）：Done 且该图在 `reference_failed` 里 → 失败（定位失败与两端搬移超限同样计数）；Done 且不在 → 定位成功，清零并清除告警；帧测量出错、该图单独出错、缺帧、超时、件不匹配（`apply_result` 返回 None）→ 没有证据，计数不变也不清除（测量出错不能证明定位恢复）。“失败”不要求该图有 fixture：生产里没有 fixture 的图不会没有基准，离线 `LocateFail`（不带 fixture）因此能演练告警与恢复。
  - 换配方：不同配方各自计数，别的配方的件不打断连续，换配方也不清除旧配方的条目。所以换到配方 B 生产后，配方 A 留下的告警一直在，直到 A 再生产且这幅图定位成功、A 新修订的第一件测完（见下），或软件重启；A 不再生产时就留到重启。拍照点编号在配方间会重名（都叫 P1），检测页横幅每条写明配方与修订，不是当前配方（`activeRecipeId`）的排在后面、淡显并标“当前未在生产”，横幅说明它要怎样才消除。没有改成换配方即清除：换回 A 时它仍在失败，告警应还在；也没有只显示当前配方的告警，否则 A 的告警在 B 生产期间不可见、换回 A 时突然出现。同一配方的修订变了（新发布或候选修订）：观测到新修订的件时删掉该配方其他修订的全部条目，已告警的记“定位告警撤销”（不是定位恢复），新模板从 0 开始计。候选调试与离线共用一个分槽，同一配方的候选修订与已发布修订交替跑时会互相清零，可接受。
  - 重启：只在内存，重启清零，与录制告警一致。理由：每件定位失败本身已是 ST_NO_REF，判 ERR 92 或让位于 NG，不会被悄悄放行，告警只是汇总；重启后仍在失败时 3 件内会重新告警。备选是启动时从历史回填，代价是读库与版本兼容，不做。
  - 复位、站点切换不清除（告警不放进每件开工、S7 复位、站点切换都会清空的 `alarms`）；真机与离线 / 候选调试分槽（口径同 `recording_health.rs`），快照只给当前分槽的告警。
  - 接线只有一个同步点：`Machine::on_measured` 在 `apply_result` 写好帧记录之后调 `observe`。出现记 err “连续定位失败”，消除记 ok “定位恢复”，作废记 info “定位告警撤销”，都挂在当前这一件的 cycle 下（`stage = locate-alarm`，data 含配方、修订、图、连续件数、原因），本件时间线里能看到；日志的拍照点、k 与相机取条目自己的（相机在条目建立时从 `Subject` 记下、不序列化给前端），作废时触发的那一帧可能是别的拍照点，不能用它的相机。`cycle://snapshot` 增加 `locateAlarms`，告警文字同时进 `alarms`（诊断抽屉的原始告警）。检测页顶部 `Alert` 逐条列出配方（修订）· 拍照点 · 图 · 连续件数 · 最近原因。文案不写“已判 ERR 92”：可能让位于 NG，或该段不判位置。不加 PLC 故障码（用户决定），不新增命令与事件。
- **页面职责。** 生产页 = 选中帧叠图、一行定位摘要、告警横幅（含不在生产的配方留下的告警）；历史页 = 按记录位姿叠图、复测位姿不同时标出；示教页 = 只在自定位没通过时画落点。只在现有查看器里加图层、一行摘要和一条告警，不改布局。
