## 各轮主要变化

- **第 1 轮**：确立“胶检测（静态走廊）与位置基准（随工件）解耦”。评审纠正了对 MX11 现场结论的过度推断，把偏差计算从新 LyFlow 算子改到 GlueSight Rust，模板改为由冻结原图派生；起草方否决了用样本均值自动校正名义偏置，并指出按站号对应在弯道上的误差，改为就近投影。
- **第 2 轮**：定下状态模型（`ST_NO_REF`）、“NG 优先于基准无效 ERR”的实现方式、删除 `LocateFailed`、base_dir 打通规则、就近投影的窗口与拐角约束。
- **第 3 轮**：名义偏置并入 `limits.position.nominal`；补全 `requiredOperators` 多处维护、离线场景、审计 spool、评测与打包自检的影响面；确认可定稿。

## 用户决定（2026-10-20）

- 定稿 §8 的 6 项：第 4 项（阶段 0 数据）改为**不重采，先用已有样本集** `gs-20261017-normal`（2026-10-17，1 件、12 点位 × 3 相机，只读）；其余 5 项按推荐执行。
- **MX11 数据不可信，忽略**。定稿 §1 已去掉以 MX11 为前提的论证：d = B − T(N) 无论胶是否随工件动都正确，静态走廊沿用已验证的胶检测与解析契约，方案不依赖 MX11。第 1–3 轮记录保持原样，其中对 MX11 的引用只作讨论过程留档。
- 样本集测不到件间胶位抖动 σ_B、实物偏移线性度、视差与高度，见定稿 §9，留待后续采集。
- 2026-10-21：final.md 第 8 节第 7、8 项按建议拍板——胶路两端新增“超出检测范围”站状态并加 `maxEndShiftMm` 护栏（示教余量 m 默认 0，G4 再定）；v1 默认 `angleRange = 0`（只找平移），开转角逐拍照点由 G4 验证决定。
