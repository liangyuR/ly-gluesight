# 教程截图

当前教程引用 24 张 PNG。文件名的编号对应教程章节，具体图注在上一级 `guide.json` 中。

除 `19-follow-probe.png` 外，均在 2026-10-09 的专用 Robot / PLC 演示实例中，通过真实桌面页面或本机联调台操作截取。没有用流程预览数据替代检测结果，也没有修改截图中的参数或判定值。

`19-follow-probe.png` 来自先前独立离线回放实例，截图时软件界面名称尚未更新；用于说明随动标定和原图试测位置，图注已注明。当前 Robot 服务模型的自动回归仍只覆盖飞拍。

更新截图时使用同名文件，优先截取完整的操作面板；保留按钮、参数和状态信息，避免只截结果而隐藏上下文。更新后运行 `pnpm guide:pdf` 并检查全部页面。
