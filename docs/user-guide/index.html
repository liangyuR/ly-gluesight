开始使用 / 01

1　先跑通一个已配置的示例

已有演示环境时，先完成一次正常件检测，再学习后面的从零配置步骤。左侧“操作流程”可以回到所有主要入口。

  1. 1启动 GlueSight。使用本仓库模拟环境时，双击 scripts/robot-plc-demo/启动联调.cmd；第一次还没有演示程序时，按第 21 节构建。
  2. 2打开本机联调台 http://127.0.0.1:8766/。确认 PLC 通讯正常、触发桥在线、视觉就绪。
  3. 3选择“正常件”，点击“运行一件”；回到 GlueSight 的“在线检测”，查看工件 SN、4/4 帧和 OK。
  4. 4前往“历史记录”，确认同一 SN 已保存。若尚未建站，请依次完成第 2 至 13 节。
“操作流程预览”使用浏览器示例数据。设备连接、原图处理和生产发布，请在桌面软件的正式页面操作。

首次建站 / 02

2　设置型号来源和图像测量

进入“系统设置”。两个设置分区分别保存，修改后要点击对应分区的“保存”。

  1. 1在“检测节拍”中，将型号来源设为“PLC 下发产品代码”。PLC 的产品代码必须与配方一致；人工调试也可选择“人工选择配方”。
  2. 2在“测量与帧录制”中，将飞拍配方设为“lyFlow 流程（沿示教中线量胶）”，填写本机 lyflow_core.dll 的实际位置。
  3. 3学习和排查时，将“帧录制”设为“全部”，并设置保留件数和空间上限；生产时按需要选择“只留 NG / ERR 件”。
  4. 4点击保存，确认引擎显示“LyFlow · 就绪”。保存节拍设置后，新的设置从下一个工件开始生效。
“模拟测量（不看图像）”只能演示节拍。沿示教中线量胶的 lyFlow 流程接入前（P0 步 L），选择图像测量时，检测与示教试测都会如实报“尚未接入”，不会用模拟值代替。

首次建站 / 03

3　配置相机并确认实际状态

进入“设备与采集”，先选中要配置的相机。示例只需要 cam1。

  1. 1学习本教程时，图像源选“模拟相机”，采集方式选“触发（飞拍）”。现场相机选择“海康 MVS”并绑定正确设备；离线数据选择“回放目录”。
  2. 2填写相机名称。现场相机还需调整曝光、增益和触发参数，然后点击相机参数区的“保存并应用”。
  3. 3查看顶部“已连接”和“实际参数状态”。存在“未接受参数”时，按具体提示调整后重新保存。
  4. 4回放模式先选择有效目录，再用“下一张”查看原图。完成配置后，通过页面下方进入飞拍工位标定。
飞拍使用触发采集；连续采集只更新预览，不进入检测。正在检测或相机仍被配方引用时，软件会限制相机修改或移除。

首次建站 / 04

4　连接 PLC 并核对握手点位

进入“PLC 通讯”。本例通过独立的 Modbus TCP 服务进行真实报文交换。

  1. 1协议选“Modbus TCP”，主机填 127.0.0.1，端口 1502，站号 1；轮询 50 ms，通信超时 1000 ms。
  2. 2保存配置并连接，确认状态为“已连接”。现场连接时，用设备实际 IP、端口、站号和点位表替换示例值。
  3. 3核对工件开始 C10、运动结束 C11、结果确认 C12、视觉就绪 C20、已布防 C21、检测中 C22 和结果有效 C23。
  4. 4核对产品代码 HR102、拍照数 HR103、结果码 HR110 和异常码 HR111。工件及结果 SN 使用两个寄存器，需与 PLC 字序一致。
独立 Robot 联调使用 Modbus TCP。软件内置“模拟节拍”使用 PLC 的“模拟器”协议；这两个入口各有用途，不能同时驱动同一工件。

首次建站 / 05

5　完成飞拍工位标定

标定将像素换算为毫米。在“飞拍工位标定”中，先获得清晰的标定板原图，再执行标定。

  1. 1选择 cam1，点击“取新样本”，或用“导入离线原图”导入该工位拍摄的棋盘格图像。
  2. 2填写棋盘格内角点数量和实际格长。本教程的合成板为 9 × 6 个内角点，格长 3.2 mm。
  3. 3点击标定按钮，检查成功状态、像素当量和误差。示例合成板约为 0.08 mm/px；现场应以实际板和相机求得的值为准。
  4. 4保持相机、镜头和工位位置稳定。更改成像位置、分辨率或镜头后，应重新标定并重新验证相关示教。
模拟相机画面按 0.112 mm/px 合成，示教取样时会自动填入这个像素当量；导入离线板图后可练习完整标定。模拟板由 scripts/robot-plc-demo/make-board.py 生成，理想合成板误差不代表现场精度。

建立配方 / 06

6　建立候选配方

在“配方库”点击“新建飞拍”。候选是编辑和试验用版本，生产版本才会被在线检测使用。

  1. 1填写唯一的配方编号、便于辨认的名称和产品代码。编号使用字母、数字、下划线或短横线，最多 32 位。
  2. 2本教程使用 ROBOT-DEMO、产品代码 101。如果库中已经存在该示例，请直接选择“配置候选”；创建自己的配方时换用未使用的编号和代码。
  3. 3点击“创建候选”，进入拍照点规划。需要调整已有产品时，在配方库打开该产品的“配置候选”。
  4. 4随时核对顶部的“候选 v…”和“生产 v…”。保存候选不会立即更改正在生产的版本。
删除配方会移除它的生产配置、候选和示教资料（示教的中线保存在配方里）；已有历史结果及当时的配方快照仍保留。

建立配方 / 07

7　规划拍照点与胶条

进入“拍照点规划”。每个拍照点在自己的相机图像里沿示教中线量胶，不再需要工件坐标里的名义胶路、拍照中心或视野。

  1. 1触发方式选“飞拍（位置比较触发）”。站距决定沿中线每隔多少毫米量一站，示例为 1 mm。
  2. 2在拍照点表里按运动顺序添加四行 P1–P4：Pose 与编号相同，相机都选 cam1，胶条填 J1。新加的一行沿用上一行的相机与胶条，中线为空。
  3. 3盘圈、大胶堆等示教不出的位置勾选“不检”：这一帧仍要到达，但不量不判。标定引用留空时用该相机的工位标定；同一 Pose 可以触发两台相机。
  4. 4“示教状态”一列只读，显示“已示教 n 点 · x mm”或“未示教”；页面上方的“胶路示教”是要检拍照点里已示教的比例。保存候选配置后进入单帧示教点出中线。
未示教的拍照点可以保存、编辑，但配方不能开工。拍照点的增删、调序在本页完成；“工件总览”中的拖动只调整显示位置。

建立配方 / 08

8　设置判定规则并检查飞拍条件

判定规则决定哪些测量结果会成为 OK、NG 或允许的局部超差。每个拍照点自成一段，段与段之间不连。先理解每项含义，再填写工艺要求。

  1. 1设置站距和中值滤波窗口；在“默认检测参数”里填搜索半宽（沿中线法向找胶的范围）、极性（暗胶条或亮胶条）和胶宽范围。
  2. 2“位置”是胶条中线相对示教中线的横向偏移，“胶宽”是沿法向量出的宽度；两项都可以单独停用。连续超出公差带超过允许长度判 NG，超过绝对上下限直接判 NG。
  3. 3“允许断胶长度”按拍照点计：同一拍照点内连续缺胶超过它判断胶。某个拍照点要用不同的检测参数或限值时，在表中展开“单独设置”勾选；取消勾选即恢复默认。
  4. 4检查飞拍可行性中的运动模糊、相邻触发间隔和帧重叠。输入实际速度、曝光及帧率，不要只看界面默认值。
默认限值取自现场图：名义胶宽 4 mm、允许断胶 6 mm。规则修改后，保存候选并重新验证代表性样本；改检测参数或站距后还要重新试测。不要为了让不合格样本通过而随意扩大工艺限值。

示教与验证 / 09

9　为每一帧取样并点出胶路中线

进入“单帧示教”，从 k1 开始。每一帧独立绑定冻结原图；中线、像素当量和检测参数保存进候选配方的这个拍照点。

  1. 1将工件和相机置于当前拍照点，点击“取新样本”；也可导入该点的完整离线原图。像素当量还没有时，取样后按相机标定自动填入（模拟相机为 0.112 mm/px）。
  2. 2在冻结原图上从胶嘴一侧往外，沿胶条中心依次点击加点（绿圈为起点）；拖动点可调整位置，点一下选中后可“删除选中点”，也可“删除末点”或“清空中线”。
  3. 3核对像素当量；需要时勾选“单独设检测参数”，填写这个拍照点的搜索半宽、极性和胶宽范围，不勾选则用配方默认值。
  4. 4点击“保存中线”。保存后原图上会叠加各站位置，下方显示中线点数、长度和站数；中线改动未保存时页面显示“中线待保存”，不能试测。
导入支持 PNG、JPEG、PGM、BMP、TIFF，单图不超过 15 MB。正式检测图像应与示教的工位和尺寸一致。设为“不检”的拍照点不需要点中线。

示教与验证 / 10

10　试测通过后保存每一帧

“保存中线”与“保存本帧示教”含义不同：前者把中线写进候选配方，后者确认这张原图按当前中线试测通过。发布前每个要检的拍照点都要完成。

  1. 1中线保存后点击“试测当前帧”，查看得分、量成比例和结果说明。沿示教中线量胶的 lyFlow 流程接入前，试测会显示“图像测量暂不可用”和具体原因，这一帧不能保存示教。
  2. 2试测通过后点击“保存本帧示教”，或“保存并示教下一帧”。重复完成 k1 到 k4。
  3. 3确认页面显示“已保存 4 / 4 帧”（不检的拍照点不计入）。任何一帧换图或改中线后，都要重新试测并保存。
  4. 4使用历史帧或新原图尝试调整后，如果需要撤回，可使用“恢复原始示教”恢复原图；恢复后按提示重新试测。
“中线待保存”或“试测已过期”都表示旧结果不能用于本次保存与发布。试测未通过时页面如实显示原因，不会当作通过。工件正在检测时，先等本件完成再取示教样本。

示教与验证 / 11

11　布置工件总览

总览用于把各拍照点放到便于理解的工件示意位置，帮助生产时定位缺陷。

  1. 1进入“工件总览”，点击各帧框，核对右侧绑定原图是否正确。
  2. 2可导入工件总览图作为背景，或先点击“自动布置”：各拍照点按计划顺序排成均匀网格。
  3. 3拖动帧框，或用方向键微调显示位置，最后点击“保存总览”。
  4. 4看到“总览已保存”后进入“验证与发布”。拍照点与中线要在拍照点规划和单帧示教里修改。
发布时，总览会随生产配方快照保存。在线查看的总览对应当前工件开始时使用的版本。

示教与验证 / 12

12　准备良品与缺陷样本

验证不能只看一张看起来正常的图。至少选择一件合格样本和一件缺陷样本，并由使用者确认期望结论。

  1. 1在“验证与发布”点击“导入原图样本组”，填写样本名称和人工期望结论。
  2. 2按 k1 到 k4，为同一件工件的每个拍照点选择一张原图，然后保存样本组。
  3. 3每导入一组后即可勾选并确认期望。继续导入或刷新同一候选，不会取消已有选择；切换候选时会加载目标候选自己的选择。
  4. 4也可选用测点布局兼容的历史测量。原图样本组会重跑图像测量，历史测量样本主要用于规则验证。
每组要包含全部拍照点的原图（含不检的拍照点），单图不超过 15 MB，整组不超过 80 MB。示例样本可用 make-samples.py 从已完成示教的 ROBOT-DEMO 候选生成。

示教与验证 / 13

13　验证一致后发布生产版本

验证检查设备、胶路示教、单帧示教、总览与代表性样本。只有当前候选、当前选择和期望对应的验证结果才可发布。

  1. 1勾选代表性样本，核对人工期望，然后点击“运行规则与图像验证”。
  2. 2查看发布前检查和每个样本的候选结论。需要显示通过，并与人工期望一致；不一致时返回对应步骤排查。
  3. 3点击“发布生产配方”，在确认窗口核对配方编号和版本，再确认发布。
  4. 4发布在工件边界生效。正在检测的工件继续使用旧快照；下一工件使用新版本，可在在线检测页核对。
截图中的候选版本可能比生产版本高，这是正常的编辑流程。学习时可以取消发布，不必反复生成生产版本。

检测与复盘 / 14

14　运行 Robot 联调并正常停止

Robot 联调台模拟运动、拍照触发和 PLC 握手。它与 GlueSight 使用相同产品代码和拍照点数量。

  1. 1确认 PLC 通讯正常、触发桥在线、视觉就绪，且 armed、busy、done 已释放。未就绪时先按界面提示处理原因。
  2. 2选择工况后点击“运行一件”，观察移动、触发、等待结果和确认的顺序。
  3. 3需要重复运行时点击“连续运行”。结束时点击“本件后停止”；看到“停止请求已收到”后等待当前工件完成，不必重复点击。
  4. 4若服务离线，先恢复服务；若存在未释放的故障握手，停止运行并排查原因，再按“故障复位”。
台架的“本件后停止”用于正常收尾，并非现场设备的急停功能。示例异常工况会有意生成 NG 或 ERR。

检测与复盘 / 15

15　在在线检测中读懂结果

“在线检测”以整件结果为中心，保留当件配方快照。先确认工件和版本，再查看帧与缺陷。

  1. 1核对顶部配方编号、版本、工件 SN 和流程状态。正常件结束后应回到空闲。
  2. 2观察拍照帧数量和每帧状态。本例完整检测应收到 4/4 帧，不能只凭 PLC 已连接判断检测完成。
  3. 3切换“整件”或“逐拍照点”：逐拍照点视图每格显示编号 · 相机 · 胶条、示教中线上各站的状态与段内缺胶位置；点击拍照点或 k1 到 k4 查看原图，原图上叠加中线与各站。
  4. 4结合展开曲线（按拍照点分段，横轴为段内弧长）和逐拍照点结果判断原因。OK 表示按当前规则通过；NG 表示测量得到缺陷；ERR 表示未能完成有效检测，需要检查设备、图像或时序。
允许的局部超差与 NG 不同，必须结合本产品规则理解。ERR 不能当成“没有检测到缺陷”。

检测与复盘 / 16

16　查历史并定位到原图

历史记录用于追溯工件、比较缺陷和导出数据。开始排查时，优先记录 SN、配方版本、结果码和原因。

  1. 1进入“历史记录”，按时间、结果和配方缩小范围。演示中主动注入了异常，所以列表里有 NG 和 ERR 是预期现象。
  2. 2点击需要检查的工件，进入详情；在逐拍照点视图或帧列表中选择对应帧，查看原图、示教中线叠加、曲线和检测原因。
  3. 3每个拍照点自成一段，断胶按同一拍照点内的连续缺胶长度判，位置写成段内弧长（如“段内 s 12.0 – 19.0 mm”）；相邻帧之间不合并。
  4. 4需要分享或分析时，按页面提供的“导出 CSV”导出记录。找不到原图时，检查是否开启录制以及保留策略。
历史列表里的“收尾”时间用于观察运动结束后的处理等待，不等于整件运动周期。

检测与复盘 / 17

17　用候选规则或原图复测

复测用于评估调整的影响。候选验证和复测不会覆盖原始生产历史。

  1. 1在历史记录中打开一件工件，在“候选对照”区域点击“使用该配方候选”。“历史复测”导航会引导你先选择历史工件。
  2. 2只想比较判定规则时，使用历史测量数据进行规则复测；批量重判可试算位置、胶宽限值和允许断胶长度。要评估中线或检测参数，需要完整原图复测。
  3. 3运行后对照原始结论和候选结论，并逐帧检查原图与缺陷差异。缺少原图或测点布局不兼容时，先补足条件。
  4. 4必要时将历史帧用于候选示教；更新示教后重新试测、验证并发布，不能跳过发布前检查。
原图复测需要录制时保存的完整图像。仅有历史数值时，不能声称已重新验证图像算法。

异常处理 / 18

18　按信号和异常码排查

先判断问题发生在设备连接、拍照采集、图像处理还是结果确认，再做对应操作。

  1. 1PLC 未连接：检查服务或设备是否启动、协议参数是否一致；查看“通讯日志”中的连接与错误记录。
  2. 2已连接但不能启动：检查视觉就绪、相机、生产配方、触发桥及 armed/busy/done 是否释放。
  3. 3收到 ERR：结合异常码定位。91 为缺帧，92 为定位失败，94 为拍照数不符，95 为产品代码未匹配配方。
  4. 4结果有效一直不释放：检查 PLC 是否发送结果确认，确认后再释放工件开始。避免连续重复发送开始信号。
处理原因后再复位和重试。修改配方应在候选中完成，验证通过后发布。

日常使用 / 19

19　日常检查与配置变更

开工前检查版本和设备，结束后保留必要证据。修改配置时沿候选、验证、发布的路径进行。

看到的状态接下来做什么
候选配置尚未保存先保存候选，再取样、验证或发布
中线待保存 或 试测已过期保存中线后，在当前图像上重新试测
图像测量暂不可用沿示教中线量胶的 lyFlow 流程尚未接入，等待步 L 完成；不要用模拟测量代替
样本选用或期望已改变重新运行规则与图像验证
等待工件边界等当前件完成，再核对下一件版本
已请求停止等待本件收尾，不再重复点击
  1. 1开工前：确认相机与 PLC 就绪、引擎可用、产品代码正确、生产版本正确；先运行一件已知良品。
  2. 2生产中：关注 ERR、缺帧、定位分数和通讯异常；检查保存原图是否符合复盘需要。
  3. 3变更时：修改候选，重新试测受影响的帧、验证代表性样本，确认后发布；下一件检查实际使用版本。
  4. 4结束时：请求本件后停止，待握手释放再关闭联调服务。备份应用数据目录及需要保留的原图、CSV 和配方资料。
正式数据目录与模拟目录分开。本仓库演示的数据在 %APPDATA%/com.xyzrobotics.gluesight.robot-plc-demo；不要把输出日志目录当成完整数据备份。

维护附录 / 20

20　模拟环境的启动与升级

本节面向维护人员。以下命令在仓库根目录执行；操作员日常使用可直接打开已经部署的桌面程序。

命令作用
pnpm sim:build首次构建，或软件升级后重新构建并启动专用桌面联调
pnpm sim:start使用已有构建启动，复用配方与历史
pnpm sim:stop等待当前件完成，再关闭登记的模拟进程
pnpm sim:test不依赖桌面和 DLL 的隔离协议回归
pnpm sim:verify在已就绪的联调环境依次运行五种工况
pnpm sim:services只启动 Robot、PLC 与联调台，不运行桌面图像检测
  1. 1首次需要 Python 3.11+、Node 22+、PowerShell 7、pnpm，以及桌面构建所需的 Rust/MSVC/WebView2 和兼容 lyFlow DLL；先安装项目依赖。
  2. 2修改端口、配方或时序时，编辑 scripts/robot-plc-demo/demo.config.json。PLC 参数改变后，在 GlueSight 中同步修改。
  3. 3升级顺序：停止模拟服务 → 运行 sim:test → sim:build → 完成就绪检查 → sim:verify。失败时根据日志排查后再使用。
详细参数、地址表、夹具与首次建站步骤见 scripts/robot-plc-demo/README.md。五工况期望依次为 1/0、13/0、90/91、90/92、90/94（结果码/异常码）。
