## 一、上线阻塞项

1. **发布 lyFlow 1.1.4**（[algorithm.md](algorithm.md) A-9）。GlueSight 打包时取 1.1 系列的最新正式版 1.1.3。它的 glue 代码与 1.1.0 相同，在 36 张正常实拍图里有 16 张误判 NG。修复（LyFlow#26–#29）都已合入 LyFlow main，但还没发版。发版流程：提升版本号 → 推送 `v1.1.4` tag → 等 CI 生成草稿 Release → 核对后正式发布 → GlueSight 执行 `pnpm deps:lyflow:update`。正式发布是对外动作，需要用户明确同意。
2. **PLC 工程师确认问题清单**（[plc-table.md](plc-table.md) 末尾，Q1–Q13）。其中会直接影响通讯的几项：
   - 协议版本写 4（Q1）；
   - `resultCode`、`faultCode` 是 VW76、VW78（Q2）；
   - SN 是字符串还是数值、最长多少、采用哪种字符串格式（Q3–Q5）；
   - TSAP 0x0102 / 0x0201 能否接入（Q9）；
   - 各设备的 IP 汇总（Q10）。
3. **真机验证**：PLC、相机、硬触发、现场节拍，以及真机模式下的发布（`validationSite=real`）都还没有验证。本轮验证全部基于虚拟 S7、实拍样本集回放（模拟标定）和本机 lyFlow。

## 三、模拟标定说明

实拍样本集没有标定（`mmPerPx=null`），各工作线按名义胶宽 4 mm 除以实测像素胶宽推算当量，取值在 0.09–0.117 mm/px 之间。这些值只用于打通业务链路，不代表现场精度。上线前必须用真机标定替换。

## 四、下一轮跟进

各工作线报告的跨线问题，由第二轮工作线处理，处理结果在 PR 中说明：

- 测试设施：生产桌面 E2E 等待的「站点模式」链接已被删除；隔离实例只探测 127.0.0.1；数据目录路径过长时 WebView2 不创建窗口且不报错。
- 稳定性：布防预算 200 ms 在高负载下偏紧；审计 spool 残留 `.tmp` 时拒绝启动；离线运行间隙心跳故障的日志噪声。
- 提示：没有可开工配方时，PLC 复位失败的原因说不清（D-CF-9）；偏移为主的断胶区间，原因文案会误导排查。
- UI：工作台提示插入导致布局跳动（需要全局 toast）；50 字符 SN 的显示布局；残留的硬编码颜色；示教笔刷默认宽度。
