# 诊断包与历史回放

运行日志及一键导出范围见[运行日志与诊断包](../architecture/agent-logging.md)。

## 8. 回放比对在哪里计算

- 问题：逐区域比对放后端并随对照结果保存，还是前端计算。
- 采用：前端由已加载的原记录（区域判定与逐帧指标）与对照结果（`Comparison.burst`）计算，比对结果不存进对照文件。对照文件只多存这次对照用的每帧指标（`Comparison.burst.frames`，按 serde 默认读，旧对照文件读入为空），供历史详情把帧组条、段布置与区域结论切换为对照结果显示；计划身份不同（如原记录是维护采集、没有分段）时逐区域比对不成立，仍可按对照结果看每帧。
- 回退：删除 `RegionReplayDiff` 即可回到只看整件结论。

## 9. 比对容差

- 采用：偏移、胶宽差超过 0.01 mm 或帧状态改变、区域结论改变，即记为差异。同一发布包、同一原图的重跑应一致：离线实测最大偏移差约 5×10⁻⁸ mm、最大胶宽差约 2×10⁻⁷ mm（f32 存储与 JSON 往返的舍入），0.01 mm 只用于吸收这类舍入；任何真实差异都会远大于它。
- 回退：修改 `REPLAY_TOLERANCE_MM`。

## 11. 逐件回看的导航

- 采用：从历史列表进入详情时，通过路由 state 带上列表筛选，前一件 / 后一件按同一筛选（如只看 NG、所选项目）和（时间, 记录号）顺序；直接打开详情时只在本件所属范围（真机 / 离线 / 调试）内导航。快捷键：← / → 在本件内切换图像，[ / ] 切换工件（Alt+← 在 WebView2 中是后退，不使用）。
- 回退：去掉详情页头部按钮与键盘监听；列表页的 `state` 无副作用。

## 12. 重跑前置条件的提示

- 采用：缺发布包、配方快照缺失、原图不完整（录制关闭、按策略未保存、录制失败、已清理或身份核验失败）时，在按钮下方列出原因；后端仍按原逻辑拒绝，绝不改用当前配方代替。原包重跑读不到某一帧时，该帧记“测量失败”、所在帧组标检测不完整，OK/NG 不变（[segment-burst.md](segment-burst.md) 第九节第 17 条）。
- 回退：删除提示，不影响后端拒绝。
