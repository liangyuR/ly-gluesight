## 运行与环境

```powershell
cargo test --manifest-path src-tauri/Cargo.toml --offline --locked --lib
pnpm test
pnpm test:ui:production
```

普通后端测试生成临时图片、数据库和录制，不需要预备原图或测量 DLL。首次构建需要 Rust MSVC、Visual Studio C++ 工具和私有 Git 依赖；依赖未缓存时先允许 Cargo 获取。

S7 专项需要 Python 3 和本机 TCP 回环权限，命令见[测试说明](TESTING.md#s7-一期握手)。耐久性子进程夹具由父测试启动，不能单独作为无用 ignored 用例移除。

桌面生产流程使用模拟 PLC/相机、真实后端、SQLite、PGM 和历史读回；它不证明真实 PLC、SDK、引擎算法质量、现场节拍或长稳。
