# 后端主业务测试（2026-10-11）

后端默认回归围绕配方、复合帧采集、示教验证发布、生产检测和结果落盘。删除过时的多独立设备成功场景、重复异常组合及辅助实现细节；生产代码、Cargo 特性和现有专项忽略配置不变。

## 保留的业务保护

| 范围 | 保留内容 |
| --- | --- |
| 配方 | 创建、保存与重载，修订号不复用，单设备图 1/2/3，发布失败不覆盖既有版本 |
| 整圈采集 | 从有效接收帧确定拍照点，核对 PLC 计划与触发数，首帧基线、设备会话、缺帧、重复、多帧和 drain；异常轮不能采用 |
| 示教与验证 | 各视图独立中线、像素当量、试测与有效 NG，修改后旧试测失效，显式不检，验证样本独立性与冻结发布身份 |
| 生产与判定 | 一个 SDK 设备复合三视图，所选视图和多视图 OR，胶宽、偏移、断胶与执行异常；截止后结果不能重复或覆盖当前件 |
| PLC 与调度 | 统一布防预算、唯一 cycle 身份、请求/结果/ACK 身份、心跳与断线、结果最后提交，阻塞任务超时后仍占用实际容量 |
| 落盘与历史 | 测量、逐拍身份、真实图片及元数据读回，写入失败回滚，ACK 和原图回调不串件，重启恢复不重复，活跃或历史引用原图受保护 |
| 资源规则 | 明确 ID、修订、尺寸、路径和结构检查；旧带 hash 字段格式拒绝或备份重建，禁止路径逃逸和错误资源关联 |

## 精简依据

- 删除三台独立相机配方、按设备分组及交错到帧的正常场景，改用一个设备的连续触发计数。缺帧、迟到帧和设备重开保护仍保留。
- 删除错误文本数字区间格式、Base64 全字节枚举、JSON 空白格式、耗时字段序列化与逐项统计、日志去重、重试计数整数极限、清理批次数与数据库查询优化等独立测试。
- 删除退避、缓存容量、TTL、配置和非法输入的重复组合；保留代表性失败、恢复和证据隔离场景。没有将删掉的矩阵包装进新增循环，也没有新增 ignored、特性门或排除列表来降低默认数量。
- 示教失效、配方版本和发布身份的有效断言集中到现有业务测试；真实 PGM 解码、导入部分失败清理、独立样本和冻结版本仍验证。
- S7 网络回环、真实 DLL 和耐久性子进程夹具继续作为现有专项保留；Windows 路径/文件锁、真实 SQLite 锁与进程终止保留代表性恢复保护。

辅助配置、格式、计时、缓存淘汰、清理优化及所有故障排列不再保证自动覆盖。业务规则相似但位于不同边界的测试仍保留必要接线检查，例如路由拒绝缺帧与最终工件不能报 OK。

## 运行与环境

```powershell
cargo test --manifest-path src-tauri/Cargo.toml --locked --lib
pnpm test
pnpm test:ui:all
```

依赖已缓存时可给 Cargo 加 `--offline`。普通后端测试的图片由夹具生成，数据库和录制写入临时目录；不需要本机预备图片或外部测量 DLL。首次构建需要 Rust MSVC、Visual Studio C++ 构建工具，以及 `Cargo.toml` 所列私有 Git 依赖的读取权限。

S7 专项需要 Python 3 和本机 TCP 回环权限，真实 DLL 专项需要 `LYFLOW_CORE_DLL`；命令与现场验证边界见[测试说明](TESTING.md)。现有耐久性子进程夹具由父测试主动启动，不能作为无用 ignored 用例删除。

前端仍保留 40 项与三条主流程，详见[前端轻量测试](frontend-lightweight-tests.md)。桌面生产流程使用模拟 PLC/相机、真实后端、SQLite、PGM 与历史读回；软件回归不替代真实 PLC、SDK、引擎 DLL 或现场准确率与长稳验收。
