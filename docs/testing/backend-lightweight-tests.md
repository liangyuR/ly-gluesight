# 后端轻量回归

更新时间：2026-10-23。本轮按实际业务回归价值精简 Rust 库测试，当前保留 **106 项默认回归与 1 项手动算法评测**。逐项源码、测试名称、保护规则和删除依据见 [Rust 保留测试清单](rust-test-retained-inventory.md)。

默认集合重点保护当前段配方、高电平门控采集、Software 单帧隔离、帧号配组、整件标定、未分段判定、PLC 请求与 ACK、发布门槛及持久化恢复。少量 S7 TCP 回环、SQLite、原图录制与资料搬迁集成测试仍保留，不能把所有库测试称为纯单元测试。

普通 PR 仅做 Format 检测、前端单测和 Rust 默认库回归；桌面、打包、脚本、长稳与算法评测均不进普通 PR。CI 入口和手动验收范围见 [测试说明](TESTING.md#windows-ci-与手动验收)。

## 运行与环境

```powershell
cargo test --manifest-path src-tauri/Cargo.toml --offline --locked --lib
```

默认集合使用临时数据，不要求现场样本、相机、PLC 或 lyFlow DLL；S7 测试使用本机随机端口，需要回环连接权限。首次构建需要项目固定的 Rust MSVC 工具链、Visual Studio C++ 工具和私有 Git 依赖；`--offline` 要求依赖已缓存。

唯一手动忽略项为 `vision::eval::algorithm_eval`，使用 `pwsh -NoProfile -File scripts/Test-AlgorithmEval.ps1`，需要现场样本和 lyFlow 运行库。原 7 项真引擎与 2 项 packaging 自检 ignored 测试已删除，不再提供相应 Rust 测试命令。

### 运行与环境

```powershell
cargo test --manifest-path src-tauri/Cargo.toml --offline --locked --lib
pnpm test
pnpm test:ui:production
```

普通后端测试生成临时图片、数据库和录制，不需要预备原图或测量 DLL。首次构建需要 Rust MSVC、Visual Studio C++ 工具和私有 Git 依赖；依赖未缓存时先允许 Cargo 获取。

S7 专项：`plc_session` 用例由进程内 S7Server 驱动，已进默认测试，只需本机 TCP 回环权限。命令见[测试说明](TESTING.md#s7-生产握手)。原审计耐久性子进程夹具已于 2026-10-22 删除（`c6c2ba5`）；当前默认忽略的用例只有需要 lyFlow 运行库或样本集的几项，见[测试说明](TESTING.md#当前保留范围)。

桌面生产流程使用离线·合成图（进程内 S7 与合成图相机）、真实后端、SQLite、PGM 和历史读回，分旧拍照点配方与段配方两段（段配方一段需要 lyFlow，见[测试说明](TESTING.md#隔离桌面与证据边界)）；它不证明真实 PLC、SDK、引擎算法质量、现场节拍或长稳。
