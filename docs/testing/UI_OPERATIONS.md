# 当前 UI 测试覆盖边界

更新时间：2026-10-12。旧基本操作验收矩阵已删除，其中许多测试文件和覆盖声明已失效。当前用例、数量与复现以[前端轻量测试](frontend-lightweight-tests.md)和[测试说明](TESTING.md)为准。

| 当前覆盖 | 验证方式 |
| --- | --- |
| 创建配方、逐帧示教、独立样本验证与发布 | `pnpm test` 中的主流程及代表性失败保护 |
| 草稿保存、旧请求隔离、生产操作锁、周期/图源身份与历史状态 | `pnpm test` 中的保留用例 |
| 启动一件至 SQLite、PGM、metadata 与历史读回 | `pnpm test:ui:production`，模拟相机与 PLC、真实后端和磁盘 |

相机/标定/PLC 表单、系统设置、日志导出、导航、图表细节、历史筛选等辅助功能没有完整单元测试矩阵。jsdom 不证明实际布局、灰度解码、原生弹窗或硬件通信；桌面模拟流程也不证明真实 PLC、SDK、算法准确率、现场节拍和长稳。

历史 UI 证据仅表示当时版本及环境的结果，不能据此声明当前全功能覆盖。
