# 基本 UI 操作验收

目标是覆盖所有基本 UI 操作，优先让离线样本通过真实操作完成取样、标定、示教、验证、检测和复盘。功能缺失时补齐功能，操作与业务状态冲突时修正逻辑。单个测试通过或覆盖率达标不代表整个目标完成。

> 2026-10-09：随动（follow）检测工况已整体移除，一期只做三相机硬触发飞拍；随动标定、随动配方、相关测试与文档条目同步删除。

## 当前离线入口

飞拍工位标定的“冻结标定样本”及单帧示教新增“导入离线原图”。支持 PNG/JPEG/PGM/BMP/TIFF；单图 15 MB 上限，后端按真实灰度像素解码，并限制解码内存和像素数。导入图像绑定当前工位或候选修订与帧；导入示教会撤销旧试测/保存状态并保留原始图像备份。离线图像没有可核实的曝光/增益，界面显示未记录。

这些入口调用原生后端。UI 测试使用受控返回值验证操作参数、失败恢复与旧请求；后端测试验证真实 PGM 解码、损坏和超限文件。完整桌面 UI 验收必须使用单独的应用标识与测试数据目录，不修改现场配置。

## 算法连接与验收状态

lyFlow 主线依赖已固定到 `5b796c35d6cafd441a24bc09e620aaae399ca5ac`，采用 Image ABI v15 的 `RunSpec.image_inputs` / `RunImageInput` 注入 `n_load.image` 的全分辨率 u8 灰度像素。核心库加载时检查飞拍和标定算子；缺少 glue 的库会给出明确原因。飞拍胶宽和实际图像坐标已传给判定与叠加显示。

真实原生专项测试已验证棋盘标定的已知比例尺、飞拍毫米距离/胶宽、不同帧缓存隔离、空白帧定位失败及跨帧缺胶；全部 38 个后端测试通过，其中 3 个专项测试使用实际 DLL。离线样本组导入失败会清理暂存资料。

隔离桌面实例的 13 组操作全部通过，包含真实棋盘原图标定、四帧完整像素示教、样本验证、发布、实际图像 OK/NG 检测和历史原图复测。报告为 `output/playwright/ui-regression/report.json`，各阶段保留独立报告和实例哈希；历史与通讯日志 CSV 也已核实实际文件。流程预览、模拟测量结果和直接调用写命令不能替代实际 UI 操作证据。

## 证据范围

界面操作测试验证用户动作、可见状态、传给后端的参数和错误恢复；原生测试验证实际灰度解码、状态持久化与图像算法；隔离桌面脚本验证 WebView 坐标、真实原图读写以及完整工作流。三个层次共同覆盖基本操作，现场相机、PLC 通讯和实物缺陷准确率仍属于设备与现场验收。
