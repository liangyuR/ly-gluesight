# 上线前实测指南（2026-10-19）

两轮上线准备已全部合入 main。本页列出实测前的准备、建议按顺序检查的项目和已知限制。各项取舍的依据见 [决策索引](../decisions/README.md)。

## 一、准备

1. 更新代码并刷新 lyFlow 运行库：依赖已升到 1.1.4，主检出 `debug/runtime/lyflow` 里的还是旧版，必须刷新。

   ```powershell
   git pull
   pnpm install --frozen-lockfile
   pnpm deps:lyflow:local            # 查看是否固定过本地运行库目录；固定过且要用正式版时加 -Clear
   pnpm deps:lyflow:dev              # 恢复 1.1.4 并复制到 src-tauri/target/debug/runtime/lyflow
   pnpm dev
   ```

   首次编译会按 tag `v1.1.4` 拉取 `lyflow-client`，需要能访问 GitHub。启动后在“总览”或“系统设置”确认测量引擎为 1.1.4。

2. 离线样本集：`C:\Users\11601\Documents\gs\2026-10-17-normal-sampleset` 没有标定（`mmPerPx=null`）。手工实测时先复制一份到短路径目录（例如 `C:\gs-tmp\hands-on\sampleset`），在副本的 `sample-set.json` 里把 `mmPerPx` 改为 `0.112`（模拟当量，与端到端夹具一致），离线控制台选这份副本。原件保持只读。

3. 数据目录路径不要太长：WebView2 资料目录超过 229 个字符时，启动会直接报错并给出路径与长度（r2-test-infra §3）。

## 二、建议检查的项目

### 1. PLC 交互表 V1.0（协议 4）

- PLC 页点“载入一期 S7 点表”，CPU 选 S7-200 SMART：默认 192.168.2.10:102、DB1（锁定）、TSAP 0x0102/0x0201、PDU 240，SN 格式默认“200 SMART 字符串”。
- 点表里 `resultCode`、`faultCode` 是 DBW76、DBW78；序号类字段是 DInt。
- PLC 日志页新增“事务”列（requestSeq），可按件筛选。
- 现场接 PLC 前，请 PLC 工程师先答复 [plc-table.md](../decisions/plc-table.md) 末尾的问题清单 Q1–Q13。

### 2. 配方全流程（离线 · 样本集）

新建配方 → 默认参数 → 整圈采集（离线产线送一圈）→ 单帧示教 → 标定验证 → 验证发布 → 投产。重点看：

- 操作成功提示改为主区顶部居中的浮层，不再推动页面；错误和需要处理的提示仍在页面内。
- 单帧示教默认笔刷 120 px。提取失败时提示加大笔刷；同组第二次失败时，“笔划直接生成中线”变为主按钮。
- 矩形框选改为“顶帽找胶 → 笔刷提取对中”，应能在这批图上框到胶本身，不再框到旁边的亮区。
- 已经作为独立验证样本入库的轮次，不能再“采用本轮图像”用于示教。
- 验证页按钮的禁用原因、采集页的主次按钮随状态变化。

### 3. 生产（离线虚拟 S7）

- 生产页按 1920×1080 一屏排布：80 px 判定字，局部超差用警告色，未测成和设备故障用故障紫，与 NG 红区分。
- 50 字符 SN 在生产页、历史列表、历史详情、运行日志中完整显示，不撑破布局。
- 布防预算默认 500 ms（原 200 ms）。离线连续运行不应再频繁出现布防超时的 ERR。
- 在线检测页长时间常开，WebView2 内存应稳定在约 400 MiB（原约 650–740 MiB）。

### 4. 故障与恢复

- PLC 断线：PC 主动断开后约 3.5 s 自动重连，重连后需要明确复位；复位被拒时提示具体原因，例如没有可开工配方。
- 心跳：离线运行间隙不应再出现“PLC 心跳超过 3000 ms 未翻转”的误报。
- 进程在事务中退出：重启后历史里会补一条 ERR 记录。离线事务留下的未结事务可以进入离线，由虚拟 PLC 复位。
- 原图目录不可写：在线检测页报警栏显示“原图录制失败”，带连续次数和原因，恢复后自动清除。
- 资料盘剩余空间不足 2 GB：暂停接件，空间恢复后自动就绪。

### 5. 历史、回放与日志

- 历史详情：可按原发布包重跑并逐拍照点比对，用 ← / → 逐件回看，查看本件事件时间线。
- 历史列表、运行日志：筛选或翻页时保留上一页数据并显示加载态，不再整块闪空。
- 运行日志页（生产 → 运行日志）：按级别和件筛选、实时跟随、导出诊断包。

## 三、已知限制

- **真机未验证**：PLC、相机、硬触发、现场节拍都没有在真机上验证。布防各阶段耗时和 500 ms 默认值需在现场专机复测；PLC 的 ArmTimeout 不得小于 `arm_ms` + 2 s（建议保持 10 s）。
- **模拟标定**：样本集的当量 0.112 mm/px 是推算值，不代表现场精度。上线前必须用真机标定替换。
- **lyFlow 1.1.5 未发布**：LyFlow#31（胶整段横移时跟过去，不再当成断口）已合入 LyFlow main，但没有发版。在发版前，突变横移仍由 GlueSight 判定兜底（#125），按位置超差报，原因中注明“胶条可能整体横移”。是否发 1.1.5 需要你决定。
- **日志保留**：运行日志上限 1 GB，满负荷（约 1 万件/天）实际只能保留约 4–5 天，不是 30 天；`plc.db` 没有容量上限。提高上限或先删 debug 行的方案见 [r2-records.md](../decisions/r2-records.md) R-6，待你按现场磁盘和节拍决定。
- **首启样例配方**：MTR-HSG-A/B 仍会写入全新站点，现场部署后需删除（core-flow D-CF-8）。
- **整组不检**：每个拍照点组必须恰好选一张检测图，不支持整组不检（core-flow D-CF-7）。
